## 2. Проблема

Сегодня у меня как у единственного пользователя накоплен разрозненный архив аудио/видеозаписей совещаний (встречи с заказчиками, проектные сессии, планёрки, ретроспективы), который по сути является **«чёрным ящиком»**: запись лежит, её никто не смотрит, содержание забывается, а контекст решений теряется через 2–3 дня.

**Текущие workaround и их ограничения:**

| Workaround | Боль |
|---|---|
| Делать заметки от руки во время встречи | Не успеваю за ораторами, теряю нить разговора, не успеваю участвовать |
| Слушать запись часами в 2x | 2 часа записи = 1 час прослушки, без поиска по смыслу, без привязки к участникам |
| Делегировать секретарю | Нет бюджета, нет секретаря, конфиденциальные встречи |
| Использовать встроенную транскрипцию Яндекс Телемоста | Работает только для текущей встречи, без хронологической истории, без привязки к решениям, без удобного экспорта в DOCX со скриншотами |
| Otter.ai / Fireflies / tl;dv | Заточены под англоязычный B2B-SaaS, требуют подписку, отправляют записи в облако третьих лиц (GDPR/152-ФЗ риск), плохо распознают русский и смешанные языки, нет интеграции с Яндекс Телемост |

**Что будет, если ничего не делать:** архив записей превратится в свалку, решения забудутся, повторяющиеся совещания будут генерировать одни и те же ошибки, ценные инсайты из разговоров с заказчиками — утеряны.

## 3. Vision Statement

> *«Для меня как единственного пользователя-аналитика я создаю локальное HTML-приложение, которое превращает любую встречу (по записи или в реальном времени через Яндекс Телемост) в структурированный хронологический протокол с транскрипцией, идентификацией ораторов, навигацией по видео и выгрузкой в DOCX со скриншотами — в отличие от облачных SaaS-сервисов, которые требуют подписку, сливают данные в чужие облака и не понимают русский язык.»*

**Краткая формулировка:**
Локальный браузерный инструмент, который превращает видео/аудио совещания (офлайн-запись или прямая трансляция Яндекс Телемоста) в хронологическую базу протоколов с транскрипцией, диаризацией ораторов и DOCX-экспортом со скриншотами экрана.

## 5. Ценностное предложение

**Главная ценность для пользователя:**
Одна встреча = один структурированный протокол за короткое время (затраты времени только на транскрипцию), без ручного конспектирования, без зависимости от облака, с возможностью вернуться к любому моменту разговора в один клик.

**Ключевые преимущества:**

1. 🔒 **100% локально** — никакие записи/транскрипции не уходят в чужие облака
2. 🇷🇺 **Русский язык** из коробки (приоритет на качество распознавания ru-RU)
3. 🎬 **Хронологическая база** — все протоколы с возможностью поиска по тексту, по дате, по участнику
4. 📅 **Календарь прошлых встреч** — визуальная навигация по истории совещаний (месяц/неделя/день)
5. 👥 **Идентификация ораторов** вручную (для MVP) и полуавтоматически (по голосовому профилю — stretch)
6. 🖥 **Скриншоты экрана** с таймкодами — для технических совещаний
7. 📄 **DOCX-экспорт** — готовый протокол для отправки участникам
8. 🔗 **Прямая интеграция с Яндекс Телемост** — без бота-участника, через embed-плеер
9. 🌐 **Кросс-платформенность** — Windows (основная) + Astra Linux (включая офлайн)

**Отличия от конкурентов:**

| Мы | SaaS-конкуренты (Otter, tl;dv, Fireflies) |
|---|---|
| Локально, без подписки | $10–30/мес за пользователя |
| Приватность (данные не уходят) | Отправляют записи в облако |
| Приоритет на русский язык | Английский в приоритете, ru — посредственно |
| Хронологическая база протоколов | Изолированные встречи |
| Скриншоты экрана в DOCX | Только транскрипция |
| Яндекс Телемост из коробки | Zoom/Meet/Teams |
| Open-source (в будущем) | Проприетарный |
