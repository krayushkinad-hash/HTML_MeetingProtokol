## User Story
**Как** Алексей (P-01),
**я хочу** открыть отдельную страницу с полным списком всех 9 моделей Whisper,
**чтобы** управлять их загрузкой, активацией и удалением через единый интерфейс.

## Контекст
- **Процесс:** Управление моделями при изменении hardware (новый GPU → download large-v3).
- **Боль персоны:** «Не знаю сколько моделей уже скачано, какую выбрать, как освободить диск».
- **Связь с Vision:** §10.5 «Управление локальной моделью».

## Acceptance Criteria

- **AC-1:** Given я навигирую на `#/whisper`, When страница загружается, Then вижу 9 карточек моделей в сетке (3 колонки × 3 ряда), отсортированных по размеру (tiny → large-v3).

- **AC-2:** Given карточка модели отображается, When я смотрю на неё, Then вижу:
  - Имя модели
  - Бейдж: `ACTIVE` (синий), `CACHED` (зелёный), `NOT CACHED` (серый)
  - Размер (expected / on disk)
  - HF repo (например `Systran/faster-whisper-tiny`)
  - Path (если скачана)
  - Кнопки: [📥 Скачать] / [✅ Сделать активной] / [🗑 Удалить]

- **AC-3:** Given я нажимаю «📥 Скачать», Then появляется прогресс-бар в карточке, polling каждую 1 сек с процентом и MB/sec.

- **AC-4:** Given я нажимаю «🗑 Удалить», Then появляется confirm dialog с именем модели, после ОК файл удаляется с диска.

- **AC-5:** Given я нажимаю «✅ Сделать активной», Then backend переключает активную модель, бейдж `ACTIVE` перемещается на эту карточку.

- **AC-6:** Given активная модель сменилась, When пользователь идёт в Settings → Transcription, Then select также обновлён на новую модель.
