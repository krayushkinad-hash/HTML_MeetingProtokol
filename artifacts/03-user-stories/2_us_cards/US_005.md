## User Story
**Как** Алексей (P-01),
**я хочу** получить транскрипцию русского языка с WER ≤15%,
**чтобы** протокол был читаемым без существенных правок.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — шаг 2 (транскрипция).
- **Боль персоны:** «Хочу получить протокол за время транскрипции, без часа правок».
- **KPI Vision:** 😊 Quality WER ≤15%.
- **Связь с Vision:** §7.1 Базовое ядро — «Транскрипция через локальный движок (Whisper / Vosk)».

## Acceptance Criteria

- **AC-1:** Given файл загружен, When я нажимаю «Транскрибировать», Then запускается фоновый процесс с моделью Whisper Large-v3 (или Vosk-ru для CPU-only).

- **AC-2:** Given идёт транскрипция, When модель обрабатывает аудио, Then я вижу прогресс (текущий фрагмент из общего числа) и оценку оставшегося времени.

- **AC-3:** Given транскрипция завершена, When я открываю протокол, Then я вижу список реплик с полями: время начала (HH:MM:SS), текст, предполагаемый оратор (SPEAKER_00, SPEAKER_01, ...).

- **AC-4:** Given тестовая выборка из 10 встреч на русском, When модель транскрибирует, Then WER ≤15% (метрика считается по библиотеке jiwer).

- **AC-5:** Given длинная запись (>2 ч), When идёт транскрипция, Then аудио подаётся в модель порциями по 30 сек, RSS не превышает 4 ГБ.

## Технические заметки
- Whisper Large-v3 (модель ~3 ГБ, требует GPU ≥8 ГБ VRAM или CPU-only с пониженной скоростью).
- Альтернатива: Vosk-ru (легче, но WER ~20–25%).
- Опционально: Yandex SpeechKit через локальный прокси (для скорости).
- Аудио нормализуется до 16 kHz mono перед подачей в модель.
- Длинные записи (>2 ч) обрабатываются в фоне, можно продолжать работу с другими протоколами.

## Связанные артефакты
- Vision: §7.1 Базовое ядро; §6.2 KPI (WER ≤15%)
- Persona: P-01 Алексей (Windows), P-03 Гость (точность влияет на «не путать реплики»)
- Risk: #6 OOM при транскрипции длинных записей
