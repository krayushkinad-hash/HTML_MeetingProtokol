# US-092: Автоматические скриншоты экрана презентации

| Поле | Значение |
|---|---|
| ID | US-092 |
| Epic | Live Mode |
| Priority | High |
| Effort | L (3-5 дней) |

**As a** пользователь в Live Mode, **I want to** автоматическое создание скриншотов при существенном изменении кадра (смена слайда / появление нового UI), **so that** у меня были автоматические маркеры с таймкодами в протоколе.

**Acceptance Criteria:**
1. Скриншот делается автоматически при значительном изменении (порог MSE / pHash > threshold).
2. Каждый скриншот имеет таймкод (timestamp совещания).
3. Скриншоты сохраняются в папку протокола + БД (с таймкодом).
4. Минимальный интервал между скриншотами (например, 10 секунд) — чтобы не было спама.
5. Есть ручная кнопка «сделать скриншот сейчас» поверх автоматики.

**Technical:**
- Разница кадров по `cv2.absdiff` или perceptual hash
- Порог чувствительности в настройках
- Debounce 10 сек между авто-скриншотами
