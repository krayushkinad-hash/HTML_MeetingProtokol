## Technical Details

### Auto-detect cuDNN (app/services/transcription.py)

```python
def _load_model(self):
    if self._model is None:
        use_device = settings.whisper_device
        use_compute = settings.whisper_compute_type
        if use_device == "cuda":
            try:
                import ctypes
                for dll_name in ["cudnn64_9.dll", "cudnn64_8.dll", "cudnn64_7.dll"]:
                    try:
                        ctypes.CDLL(dll_name)
                        break
                    except OSError:
                        continue
                else:
                    # No cudnn — fallback to CPU
                    use_device = "cpu"
                    use_compute = "int8"
            except Exception:
                use_device = "cpu"
                use_compute = "int8"
```

### Installation (Windows)

См. `docs/INSTALL_GPU.md` для пошаговой инструкции:

1. NVIDIA Driver ≥ 525
2. CUDA Toolkit 12.x
3. cuDNN 9.x (скопировать DLL в `CUDA\v12.6\bin\`)
4. `pip install faster-whisper==1.0.3`
5. `.env`: `WHISPER_DEVICE=cuda`
