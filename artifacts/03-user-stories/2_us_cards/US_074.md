# US-074: Загрузка файла скриншота (multipart upload)

| Поле | Значение |
|---|---|
| **ID** | US-074 (перенос US-047 для backend) |

| **Приоритет** | Should |
| **Story Points** | 2 |

| **Форма** | ProtocolView → ScreenshotsTab |
| **API** | `POST /api/v1/hmp/screenshots/upload` |

## User Story
**Как** Алексей (P-01),
**я хочу** загрузить файл изображения (.png/.jpg) из протокола,
**чтобы** прикрепить скриншот совещания к таймкоду.

## Контекст
- **Процесс:** Во время просмотра протокола вручную добавить важный кадр.
- **Боль персоны:** «Хочу прикрепить слайд презентации прямо к этому моменту».
- **Связь с Vision:** §7.4 «Скриншоты из видео».

## Acceptance Criteria
- **AC-1:** Given я нажимаю "📷 Скриншот" в video-player, When выбираю файл, Then файл сохраняется на диск и появляется в табе "Скриншоты".
- **AC-2:** Given загружен PNG/JPG до 5MB, When загрузка успешна, Then вижу превью в списке скриншотов.
- **AC-3:** Given файл > 5MB или не PNG/JPG, When загружаю, Then ошибка 413/415 с понятным сообщением.

## Технические заметки

### Endpoint:
```
POST /api/v1/hmp/screenshots/upload
multipart/form-data:
  - file: PNG/JPG file
  - protocol_id: UUID
  - timestamp_sec: float (опционально)
```

### Response:
```json
{
  "id": "uuid",
  "protocol_id": "uuid",
  "file_path": "C:\\...\\.html_mp\\protocols\\{pid}\\screenshots\\{uuid}.png",
  "timestamp_sec": 123.45,
  "created_at": "2026-09-21T..."
}
```
