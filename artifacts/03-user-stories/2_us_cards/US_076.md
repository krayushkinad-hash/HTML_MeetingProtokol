# US-076: Inline статус модели Whisper в Settings → Transcription

| Поле | Значение |
|---|---|
| **ID** | US-076 |
| **Эпик** | EPIC-SETTINGS |
| **Приоритет** | Should |
| **Story Points** | 2 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | SettingsPage → TranscriptionTab |
| **API** | GET /whisper/status/{name} |

## User Story
**Как** Алексей (P-01),
**я хочу** видеть статус текущей выбранной модели Whisper прямо в настройках (скачана/нет, размер на диске),
**чтобы** понимать нужно ли скачивать модель перед использованием.

## Контекст
- **Процесс:** После установки, перед первой транскрипцией.
- **Боль персоны:** «Выбрал large-v3 в настройках, а она не скачана — потом ждать 30 минут загрузку».
- **Связь с Vision:** §10.5 «Управление локальной моделью».

## Acceptance Criteria

- **AC-1:** Given открыта страница Settings → Transcription, When загружается виджет, Then отображается статус текущей модели: «✓ large-v3 скачана (3100 MB)» зелёным ИЛИ «⚠ large-v3 НЕ скачана (3100 MB)» красным.

- **AC-2:** Given статус «НЕ скачана», When виджет загружен, Then появляется кнопка «📥 Скачать модель».

- **AC-3:** Given я нажал «Скачать», When запустилось скачивание, Then появляется прогресс-бар с процентом и MB/sec скоростью, polling каждые 1.5 сек.

- **AC-4:** Given модель скачана (100%), Then автоматически: статус меняется на зелёный, кнопка «Скачать» исчезает.

- **AC-5:** Given я сменил select модели, When это происходит, Then статус автоматически обновляется (polling 5 сек).

- **AC-6:** Given backend недоступен, When статус не загружается, Then виджет показывает серое «ⓘ Статус недоступен».

## Технические заметки

```js
// Status widget логика
async function updateWhisperStatus() {
    const model = selectedModel.value;
    const status = await api.getWhisperModelStatus(model);
    if (status.downloaded) {
        showGreen(`${model} скачана (${status.size_mb} MB)`);
        hideDownloadButton();
    } else {
        showRed(`${model} НЕ скачана (~${status.expected_size_mb} MB)`);
        showDownloadButton();
    }
}

setInterval(updateWhisperStatus, 5000);
```
