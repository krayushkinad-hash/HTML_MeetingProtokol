# US-091: Формат таймкодов в DOCX-экспорте

| Поле | Значение |
|---|---|
| ID | US-091 |
| Epic | Экспорт |
| Priority | Medium |
| Effort | S (0.5 дня) |

**As a** пользователь, **I want to** чтобы DOCX-протокол содержал таймкоды в формате ЧЧ:ММ:СС, **so that** отчёт был консистентным и читаемым.

**Acceptance Criteria:**
1. Таймкоды в DOCX отображаются как `00:12:34` (ЧЧ:ММ:СС).
2. Если длительность < 1 часа, формат `MM:SS` (`12:34`).
3. Секунды округляются до целого.
4. Каждая реплика имеет свой таймкод в начале строки.
