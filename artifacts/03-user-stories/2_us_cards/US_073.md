## User Story
**Как** Алексей (P-01),
**я хочу** вставить ссылку на YouTube/Yandex Telemetry/Telemost и сразу получить протокол,
**чтобы** не скачивать файл вручную.

## Контекст
- **Процесс:** Загрузка протокола (вместо локального файла — URL).
- **Боль персоны:** «Запись совещания на Я.Телемост — не хочу скачивать .mp4, загружать, ждать».
- **Связь с Vision:** §7.2 «Импорт по ссылке».

## Acceptance Criteria
- **AC-1:** Given я вставляю URL на YouTube/Telemost/Direct link, When я нажимаю "Загрузить по ссылке", Then через 30-60 сек появляется новый протокол с транскрипцией.
- **AC-2:** Given URL невалидный (404, private, no audio), When я отправляю запрос, Then получаю 400/422 с понятным сообщением.
- **AC-3:** Given URL ведёт на большой файл (>500MB), When я отправляю, Then backend стримит загрузку и не падает с OOM.
