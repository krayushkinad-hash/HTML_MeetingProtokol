# US-087 — Закладки "Важное" для реплик

**Epic:** US-005 — Транскрипция (UX improvements)
**Priority:** Medium
**Status:** Done (2026-09-23)
**Effort:** 2 SP
**Refs:** E172, US-083

## User Story

> Как **пользователь** слушающий длинную запись,
> я хочу **пометить важные реплики звездочкой ⭐**,
> чтобы **быстро вернуться к ним позже** через фильтр.

## Acceptance Criteria

- [x] Каждая реплика имеет кнопку `☆` / `⭐` в toolbar
- [x] Клик `☆` → POST → звездочка закрашивается, реплика получает класс `is-important`
- [x] Повторный клик → снимает закладку
- [x] Желтая рамка слева у реплики с закладкой
- [x] Поле `Utterance.important: bool` уже было в БД (миграция не нужна)
- [x] Возвращается в API response (`UtteranceResponse.important`)
- [x] Endpoint: `PATCH /api/v1/hmp/utterances/{id}/important`

## Technical Design

### Backend

```python
class UtteranceUpdateImportant(BaseModel):
    important: bool

@router.patch("/utterances/{utterance_id}/important")
async def toggle_utterance_important(...):
    utterance.important = body.important
    await db.commit()
    return _to_response(utterance)
```

### Frontend

```javascript
// Render: кнопка ☆ / ⭐
const importantBtn = u.important
    ? `<button class="btn-tiny btn-important-marked" data-utterance-id="${u.id}">⭐</button>`
    : `<button class="btn-tiny btn-mark-important" data-utterance-id="${u.id}">☆</button>`;

// Handler с guard (E171):
panel.querySelectorAll('.btn-mark-important:not([data-wired])').forEach(btn => {
    btn.dataset.wired = '1';
    btn.addEventListener('click', async () => {
        await api.toggleUtteranceImportant(utteranceId, true);
        // Переключаем классы вместо outerHTML
        btn.classList.remove('btn-mark-important');
        btn.classList.add('btn-important-marked');
    });
});
```
