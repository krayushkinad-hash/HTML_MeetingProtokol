## User Story
**Как** Алексей (P-02, в командировке в Astra Linux без интернета),
**я хочу** открыть календарь прошлых встреч и прочитать транскрипцию полностью без сети,
**чтобы** подготовиться к встрече с заказчиком без необходимости выходить в интернет.

## Контекст
- **Процесс:** «Подготовка к встрече в командировке» — упрощённый процесс (только просмотр).
- **Боль персоны:** «В офлайне я как рыба на суше — единственное, что спасает — локальная база».
- **Допущение Vision:** «В Astra Linux без сети доступен только режим просмотра истории».
- **KPI Vision:** 🌐 Cross-platform — «Время старта в Astra Linux офлайн ≤3 сек».

## Acceptance Criteria

- **AC-1:** Given я в Astra Linux, нет сети, When я открываю приложение, Then главная страница с календарём загружается за ≤3 сек.

- **AC-2:** Given я открыл приложение офлайн, When я переключаюсь между вкладками «Календарь», «Список протоколов», «Поиск», Then всё работает без сетевых запросов.

- **AC-3:** Given я открыл протокол офлайн, When я смотрю транскрипцию, Then текст, таймкоды, имена ораторов отображаются корректно (всё из локального хранилища).

- **AC-4:** Given я нажал на реплику с таймкодом офлайн, When идёт воспроизведение видео, Then видео проигрывается из локального файла (без обращения к серверу).

- **AC-5:** Given я пытаюсь выполнить операцию, требующую сети (новая транскрипция, Яндекс Телемост), When нет подключения, Then я вижу понятное сообщение «Эта функция недоступна в офлайн-режиме. Синхронизация возможна на Windows».

- **AC-6:** Given приложение работает офлайн, When я хочу найти протокол, Then поиск по транскрипции работает локально (по локальному индексу в IndexedDB).

## Технические заметки
- Архитектура: local-first. Все данные — в IndexedDB + файловой системе.
- Backend (FastAPI) запускается локально, без обращения к внешним сетям.
- Видео хранится как обычные файлы на диске (`/home/user/.html_mp/protocols/<id>/video.mp4`).
- Никаких CDN, никаких внешних API, никаких WebSocket к внешним серверам.
- AI-фичи (саммари, эмбеддинги) автоматически отключаются в офлайне.
