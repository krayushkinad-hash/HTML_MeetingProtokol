# US-057: Настройки Telegram бота

| Поле | Значение |
|---|---|
| **ID** | US-057 |
| **Эпик** | EPIC-SETTINGS |
| **Приоритет** | Could |
| **Story Points** | 2 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | SettingsPage → BotTab |
| **API** | GET/PATCH /api/v1/hmp/user-setting |

## User Story
**Как** Алексей (P-01),
**я хочу** настроить Telegram бота (токен, webhook, разрешённых пользователей),
**чтобы** управлять протоколами через мессенджер.

## Контекст
- **Процесс:** Настройка дополнительных интеграций.
- **Боль персоны:** «Хочу управлять протоколами с телефона».
- **Связь с Vision:** §7.4 Telegram бот как AI-прокси.

## Acceptance Criteria

- **AC-1:** Given я открыл «Настройки → Telegram», When загружается страница, Then отображается поле «Bot Token» (password type).

- **AC-2:** Given я ввёл Bot Token, When сохраняю, Then он шифруется и сохраняется в БД.

- **AC-3:** Given я ввёл Webhook URL, When сохраняю, Then backend может получать обновления от Telegram.

- **AC-4:** Given я ввёл список Telegram ID через запятую, When сохраняю, Then только эти пользователи могут использовать бота (whitelist).

- **AC-5:** Given я включил «Уведомления», When завершается транскрипция, Then бот отправляет сообщение пользователю.

## Технические заметки
- Bot Token получается через @BotFather
- Webhook требует публичный URL (HTTPS)
- Whitelist — критическая security feature (только свои пользователи)
- Шифрование: Fernet с ENCRYPTION_MASTER_KEY
