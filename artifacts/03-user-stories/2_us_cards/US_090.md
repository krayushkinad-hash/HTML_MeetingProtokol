# US-090: Перемотка плеера по клику на таймкод

| Поле | Значение |
|---|---|
| ID | US-090 |
| Epic | Транскрипт |
| Priority | High |
| Effort | M (1-2 дня) |

**As a** пользователь, **I want to** кликнуть на таймкод в реплике транскрипта и чтобы видео/аудио плеер перемотался на этот момент, **so that** я могу быстро найти соответствующий фрагмент в записи.

**Acceptance Criteria:**
1. Каждая реплика отображает таймкод (формат ЧЧ:ММ:СС или MM:SS для коротких).
2. Таймкод — кликабельный элемент (иконка или кнопка ⏱).
3. При клике плеер прокручивается на `video.currentTime = start_sec`.
4. Если реплика активна (близко к currentTime) — таймкод подсвечивается.
5. Поддерживаются m4a, webm, mp4 форматы.

**Technical:**
- `video.currentTime = start_sec`
- После перемотки сохранять паузу/воспроизведение как было
