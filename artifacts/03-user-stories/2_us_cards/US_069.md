# US-069: Открыть папку с файлом в проводнике

| Поле | Значение |
|---|---|
| **ID** | US-069 |
| **Эпик** | EPIC-FILE |
| **Приоритет** | Should |
| **Story Points** | 2 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | ProtocolView → file-info |
| **API** | GET /api/v1/hmp/audio-files/{id}/open-folder |

## User Story
**Как** Алексей (P-01),
**я хочу** открыть папку с исходным файлом видео прямо из протокола,
**чтобы** быстро найти его в проводнике без копирования пути.

## Контекст
- **Процесс:** Просмотр протокола.
- **Боль персоны:** «Скопировал путь, открыл проводник, Ctrl+V, Enter... это долго».
- **Связь с Vision:** §7.5 «Локальная работа с файлами».

## Acceptance Criteria

- **AC-1:** Given я вижу файл в протоколе, When я нажимаю "📂 Открыть папку", Then открывается Проводник Windows с выделенным файлом.

- **AC-2:** Given путь невалидный или файл удалён, When я нажимаю кнопку, Then показывается Toast "Папка не найдена".

- **AC-3:** Given файл на сетевом диске или SMB шаре, When я нажимаю кнопку, Then открывается через UNC путь.

- **AC-4:** Given я использую Astra Linux (Linux), When я нажимаю кнопку, Then открывается файловый менеджер (xdg-open) с папкой.

- **AC-5:** Given я использую macOS, When я нажимаю кнопку, Then открывается Finder с выделенным файлом.

## Технические заметки

### Backend — кроссплатформенное открытие:

```python
# Windows: открывает Проводник с выделением файла
subprocess.run(['explorer', '/select,', file_path])

# Linux: открывает файловый менеджер (xdg-open)
subprocess.run(['xdg-open', str(Path(file_path).parent)])

# macOS: открывает Finder с выделенным
subprocess.run(['open', '-R', file_path])
```

### Эндпоинт:
`GET /api/v1/hmp/audio-files/{audio_file_id}/open-folder` — открывает на клиенте или на сервере?

**Решение:** На клиенте (через JavaScript, без backend-запроса). См. AC-1 в фронтенде:
- Для Windows: копируем путь + вызываем протокол file://
- Для Linux/macOS: используем fetch + navigator API или просто копируем

**Использование `window.open(file://path)` НЕ работает в современных браузерах** для безопасности.

**Альтернатива:** показывать диалог с инструкцией "Откройте папку вручную:" с ссылкой "📋 Скопировать" и "📂 Открыть".

### Финальный дизайн (после анализа):

| Действие | Поведение |
|---|---|
| Кнопка "📂 Открыть в проводнике" | Показывает инструкцию + Toast "Скопируйте путь и вставьте в проводник" |
| Кнопка "📋 Скопировать путь" | УЖЕ есть — копирует в буфер обмена |
| Ссылка file:// открывается | Нативно через `<a target="_blank">file:///...</a>` |

## Реализация
- Backend: `routers/audio.py` — новый endpoint `POST /audio-files/{id}/open-folder`
- Backend: использует `platform.system()` для определения ОС
- Frontend: `views/protocol.js` — кнопка "📂 Открыть папку" в file-info
- Frontend: при клике копирует путь и показывает toast с инструкцией
