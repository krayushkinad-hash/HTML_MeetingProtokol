# US-026: Извлечение решений (Decisions) из транскрипции

| Поле | Значение |

## User Story
**Как** Алексей (P-01),
**я хочу** после встречи получить автоматически извлечённый список принятых решений с указанием, кто и когда их принял,
**чтобы** через полгода можно было найти, на основании чего было принято ключевое решение по проекту.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — параллельно с саммари и задачами.
- **Боль персоны:** «Через 3 месяца заказчик спрашивает "почему выбрали PostgreSQL?". Я не помню — было на встрече в апреле. Хочу искать по решениям».
- **Боль P-03:** «Хочу быть уверен, что моё мнение учтено / не учтено корректно зафиксировано».
- **Связь с Vision:** §7.1 — «Извлечение решений»; §6 Цель #6 «AI-фичи».

## Acceptance Criteria

- **AC-1:** Given транскрипция завершена, When я нажимаю «Извлечь решения», Then LLM возвращает JSON:
  ```json
  [
    {"decision": "Используем PostgreSQL 16 для нового сервиса", "decided_by": "Алексей + Иван", "context": "Обсуждали MySQL vs Postgres", "replica_id": 12456, "confidence": "high"},
    {"decision": "Перенести релиз на 15 ноября", "decided_by": "Команда", "context": "Не успеваем к 1 ноября", "replica_id": 12789, "confidence": "medium"}
  ]
  ```

- **AC-2:** Given решения извлечены, When я открываю вкладку «Решения», Then я вижу список карточек: «Что решили» / «Кто решил» / «Контекст» / «Источник (▶ HH:MM:SS)».

- **AC-3:** Given я хочу отредактировать решение, When я нажимаю «✎ Редактировать», Then поля становятся редактируемыми, изменения сохраняются.

- **AC-4:** Given LLM пометила решение как «medium confidence» (сомнительно — явно не было сказано «решили»), When я смотрю список, Then такие решения отображаются с иконкой ⚠ и tooltip «Неявное решение. Проверьте по контексту».

- **AC-5:** Given я хочу добавить решение вручную, When я нажимаю «+ Добавить решение», Then открывается форма (текст, кто, контекст, ссылка на реплику).

- **AC-6:** Given я экспортирую DOCX, When я выбираю шаблон, в котором есть секция «Решения», Then решения попадают в выходной документ отдельным разделом с галочкой ✅.

- **AC-7:** Given я делаю поиск по решениям (US-010 с фильтром), When я ищу «PostgreSQL», Then находятся протоколы, где есть решение о PostgreSQL (даже если в транскрипции слово «PostgreSQL» не звучало в явном виде).

## Технические заметки
- Промпт для LLM: «Извлеки ВСЕ принятые решения из транскрипции. Решение — это фраза, где участники договорились о чём-то ("решили", "договорились", "будем делать так"). Укажи confidence: high (явное "решили"), medium (подразумевается из обсуждения), low (единичный участник предложил, не подтверждено)».
- Хранение: `decisions (id, protocol_id, text, decided_by, context, replica_id, confidence, is_manual, created_at)`.
- Отличие от action_items (US-023): action = «кто-то что-то СДЕЛАЕТ», decision = «что-то РЕШЕНО сделать/использовать».
