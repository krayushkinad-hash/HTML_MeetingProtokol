# US-033: Push-уведомления в браузере (Web Push API)

| Поле | Значение |
|---|---|
| **ID** | US-033 |
| **Эпик** | EPIC-NOTIFY |
| **Приоритет** | Should |
| **Story Points** | 5 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | SettingsPage → NotificationsTab |
| **API** | POST /api/v1/push/subscribe, POST /api/v1/push/unsubscribe |

## User Story
**Как** Алексей (P-01),
**я хочу** получать push-уведомления в браузере о ключевых событиях (транскрипция завершена, протокол готов, ошибка обработки),
**чтобы** не сидеть в приложении, ожидая завершения длительной операции.

## Контекст
- **Процесс:** Все этапы «Подготовка протокола» — уведомления о завершении.
- **Боль персоны:** «Запустил транскрипцию 2-часовой записи, переключился на другую работу. Push-уведомление "Готово" сэкономит мне 5 мин проверок».
- **Связь с Vision:** §7.1 — уведомления о завершении операций.
- **KPI:** Время реакции пользователя на завершение обработки ≤30 сек (без уведомлений — до 5 мин).

## Acceptance Criteria

- **AC-1:** Given я открыл приложение впервые, When я перехожу в Настройки → Уведомления, Then я вижу кнопку «Включить уведомления», при клике запрашивается разрешение браузера (`Notification.requestPermission()`).

- **AC-2:** Given разрешение получено, When я подписался (Service Worker + Push subscription), Then кнопка меняется на «Уведомления включены ✓», подписка сохраняется в БД.

- **AC-3:** Given транскрипция завершилась, When я в другой вкладке браузера, Then появляется push-уведомление «Транскрипция готова» с текстом «Протокол "Встреча с заказчиком Х" готов к просмотру» и кнопкой «Открыть».

- **AC-4:** Given я кликнул на уведомление, When браузер переключает фокус, Then приложение открывается на странице соответствующего протокола.

- **AC-5:** Given у меня несколько завершённых операций, When я смотрю на уведомления, Then я получаю:
  - «Транскрипция готова» (зелёная иконка)
  - «Саммари готово» (синяя)
  - «Ошибка обработки» (красная, с кнопкой «Повторить»)

- **AC-6:** Given я хочу отключить уведомления, When я нажимаю «Отключить» в Настройках, Then подписка удаляется с сервера, уведомления больше не приходят.

- **AC-7:** Given я в Astra Linux офлайн, When я пытаюсь подписаться, Then я вижу «Push-уведомления требуют HTTPS или localhost. В офлайне уведомления работать не будут».

- **AC-8:** Given я подписан, When проходит 7 дней без активности, Then подписка автоматически проверяется и обновляется (refresh endpoint).

## Технические заметки
- Web Push API + Service Worker (`/sw.js`).
- VAPID ключи для аутентификации push-сервера.
- Backend: библиотека `pywebpush`.
- Хранение: `push_subscriptions (id, user_id, endpoint, p256dh, auth, created_at)`.
- События для уведомлений: `transcription.completed`, `summary.completed`, `diarization.completed`, `error`.
- Throttling: не более 5 уведомлений в час (антиспам).
