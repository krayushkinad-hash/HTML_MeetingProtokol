# US-024: Экспорт протокола в DOCX со скриншотами экрана

## User Story
**Как** Алексей (P-01),
**я хочу** экспортировать протокол в DOCX, в который встроены скриншоты экрана демонстранта с привязкой к репликам и таймкодам видео,
**чтобы** участники встречи видели не только текст, но и то, что показывалось на экране в момент обсуждения.

## Контекст
- **Процесс:** Этап «Экспорт результата» (финальный шаг после саммари, задач, решений).
- **Боль персоны:** «На технической встрече 50% контекста — это код/схемы на экране. Без скриншотов протокол теряет смысл».
- **Связь с Vision:** §7.1 — «Экспорт DOCX со скриншотами»; §5 Преимущество #7 «DOCX-экспорт».
- **Зависимость:** US-015 (DOCX с таймкодами), US-016 (скриншоты), US-017 (гиперссылки), US-046/US-047 (источники скриншотов).

## Acceptance Criteria

- **AC-1:** Given протокол готов и содержит скриншоты, When я открываю диалог экспорта и выбираю «DOCX (полный)», Then формируется файл со структурой:
  - Титульный лист (название встречи, дата, участники)
  - Саммари
  - Решения (см. US-026)
  - Action Items (см. US-023)
  - Транскрипция с таймкодами
  - Скриншоты, привязанные к репликам

- **AC-2:** Given я экспортирую, When идёт генерация, Then я вижу прогресс-бар (US-020) с этапами: «Сборка метаданных» → «Встраивание скриншотов» → «Финализация DOCX».

- **AC-3:** Given файл сформирован, When я открываю DOCX, Then скриншоты встроены как изображения (jpg/png), масштабированы до 15 см по ширине, подписи под ними: «Рисунок N. Скриншот в момент реплики [Имя] в HH:MM:SS».

- **AC-4:** Given скриншотов >30, When идёт экспорт, Then DOCX сжимается: изображения конвертируются в JPEG quality=85, итоговый размер ≤50 МБ.

- **AC-5:** Given видео содержит таймкоды, When DOCX сформирован, Then рядом с каждой репликой стоит гиперссылка «▶ HH:MM:SS» на локальный видеофайл (US-017).

- **AC-6:** Given у меня нет скриншотов (загружен только аудиофайл), When я экспортирую, Then блок скриншотов пропускается, DOCX содержит только текстовые секции.

- **AC-7:** Given я экспортирую 10 раз подряд, When идёт каждая операция, Then каждая генерация занимает ≤10 сек для 2-часовой встречи с 30 скриншотами (KPI).

## Технические заметки
- Формат DOCX — стандарт Краюшкина (TNR 12, поля 20/10/10/10, заголовки, таблицы «Сетка таблицы»).
- Backend использует `python-docx` + `Pillow` для встраивания изображений.
- Изображения: `~/.html_mp/protocols/<id>/screenshots/<HH-MM-SS>.png`.
- Сжатие: при размере DOCX >50 МБ → JPEG q=85 + warning.
- Подписи рисунков через SEQ-поле для автонумерации.
- Имя файла: `protocol_<YYYY-MM-DD>_<title>.docx` (транслитерация для отправки).
