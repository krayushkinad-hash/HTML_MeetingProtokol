# US-012: Цветовая дифференциация ораторов в транскрипции

| Поле | Значение |
|---|---|
| **ID** | US-012 |
| **Эпик** | EPIC-TRANS |
| **Приоритет** | Should |
| **Story Points** | 2 |
| **Персона** | P-01 Алексей (Windows), P-03 Гость |
| **Форма** | ProtocolView → TranscriptTab |
| **API** | — (UI + GET /api/v1/speakers) |

## User Story
**Как** Алексей (P-01),
**я хочу** видеть реплики разных ораторов в транскрипции с разным цветом фона / маркера,
**чтобы** визуально мгновенно отличать, кто говорит — без чтения имени.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — шаг «Просмотр транскрипции».
- **Боль персоны:** «10 человек на встрече — список реплик выглядит однообразно, тяжело сканировать глазами, кто где».
- **Боль P-03:** «Хочу быстро находить свои реплики — мой цвет должен бросаться в глаза».
- **Связь с Vision:** §7.1 — визуальная дифференциация ораторов; §5 Преимущество #5.

## Acceptance Criteria

- **AC-1:** Given в протоколе 3 оратора, When я открываю транскрипцию, Then каждый оратор имеет свой цвет (фон слева от реплики + цветная вертикальная полоса 4px): Алексей — синий (#3b82f6), Мария — зелёный (#16a34a), Иван — оранжевый (#d97706).

- **AC-2:** Given у меня 5+ ораторов, When я смотрю на палитру, Then цвета генерируются автоматически из HSL-пространства (HSL с шагом 360°/N), с достаточным контрастом (WCAG AA ≥3:1).

- **AC-3:** Given я смотрю транскрипцию, When я навожу на реплику, Then полоса усиливается (становится 6px), появляется tooltip с именем оратора.

- **AC-4:** Given я отключил цвета в настройках (Accessibility: «Цветовая слепота»), When я смотрю транскрипцию, Then вместо цветов — паттерны (полосатый / точечный / диагональный фон) и/или крупные инициалы оратора.

- **AC-5:** Given я переименовал оратора (US-003), When я смотрю транскрипцию, Then его цвет НЕ меняется (цвет привязан к speaker_id, не к имени) — чтобы было стабильно.

## Технические заметки
- Генерация палитры: HSL hue ∈ [0, 360) с шагом `360 / count`, saturation=70%, lightness=55%.
- Цвет хранится в `speakers.color_hex` (назначается при создании оратора).
- CSS: `.replica-speaker-X { border-left: 4px solid #...; background: linear-gradient(...); }`.
- Для accessibility: опция `prefers-color-scheme` + `prefers-contrast` через media queries.
- Не использовать красный/зелёный только (проблема для дейтеранопии).
