# US-009: Голосовая пометка фрагмента в live mode (tag)

| Поле | Значение |
|---|---|
| **ID** | US-009 |
| **Эпик** | EPIC-TELEMOST |
| **Приоритет** | Should |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | LiveMode → TranscriptPanel |
| **API** | POST /api/v1/live/protocols/{id}/tags |

## User Story
**Как** Алексей (P-01),
**я хочу** во время встречи нажать горячую клавишу (например, Ctrl+Shift+T) и пометить текущий фрагмент реплики как важный,
**чтобы** после встречи быстро найти ключевые моменты и они попали в саммари.

## Контекст
- **Процесс:** «Онлайн-встреча в Яндекс Телемост» — параллельный процесс (см. US-019/US-030).
- **Боль персоны:** «Во время встречи не успеваю записывать — нужна "отметка" на реплике, которая потом попадёт в саммари».
- **Связь с Vision:** §7.1 — «Онлайн-режим: теги для важных реплик».
- **Зависимость:** US-030 (Live Mode).

## Acceptance Criteria

- **AC-1:** Given идёт встреча в live mode, When я нажимаю Ctrl+Shift+T (или кнопку ⭐ в правой панели), Then текущая реплика помечается как важная (tag = «important»), появляется визуальный маркер ⭐/звезда слева от реплики.

- **AC-2:** Given я пометил 3 реплики во время встречи, When я открываю протокол после встречи, Then я вижу 3 реплики с иконкой ⭐, которые можно отфильтровать («Показать только важные»).

- **AC-3:** Given пометка поставлена, When я навожу на иконку ⭐, Then вижу tooltip «Помечено во время встречи в HH:MM:SS».

- **AC-4:** Given я хочу добавить текстовый комментарий к пометке, When я навожу на ⭐ и нажимаю «+», Then появляется мини-форма для ввода комментария (например, «обсудить с заказчиком»).

- **AC-5:** Given встреча завершилась, When формируется саммари (US-022), Then помеченные реплики попадают в раздел «Ключевые моменты» с комментариями Алексея.

- **AC-6:** Given я случайно нажал горячую клавишу, When я нажимаю Ctrl+Shift+T повторно на той же реплике, Then пометка снимается.

## Технические заметки
- Frontend: KeyboardEvent listener на `keydown` для `Ctrl+Shift+T`.
- Backend: `replica_tags (id, replica_id, tag_type, comment, created_at)`.
- Альтернативный input: голосовая команда «пометь» (через распознавание wake-word, опционально для v2).
- WebSocket: событие `tag_created` транслируется всем подключённым клиентам (для второго экрана / ассистента).
- Audit log (US-042): создание/удаление тегов.
