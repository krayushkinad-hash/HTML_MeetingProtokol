## User Story

> Как **пользователь**, я хочу **видеть живой список реплик без рывков**,
> **с цветными badges спикеров**, чтобы **читать было удобно** и **понимать кто говорит**.

## Acceptance Criteria

- [x] Repплики добавляются через append-only (E133) — скролл сохраняется
- [x] Нет двойного polling (E134)
- [x] Auto-tab при старте транскрибации (E136)
- [x] Компактные плашки ~30px (E143)
- [x] Всегда показывать badge, даже если только speaker_id есть (E144)
- [x] Перерисовка при AI cleanup
- [x] Финальная перезагрузка при completed

## Technical Design

### Append-only rendering (E133)

```javascript
async function appendUtteranceItems(protocolId, items) {
    const list = panel.querySelector('.transcript-list');
    if (!list) { /* create structure */ }
    for (const u of items) {
        list.insertAdjacentHTML('beforeend', renderUtteranceItem(u, speakers));
    }
    panel.querySelector('.transcript-toolbar .text-muted').textContent = 
        `${list.children.length} реплик`;
}
```

### Speaker badges трёхуровневый fallback (E144)

```javascript
function renderUtteranceItem(u, speakers, fallbackSpeakers = null) {
    let speaker = null;
    
    // 1. По u.speaker_label
    if (u.speaker_label) {
        speaker = speakers.find(s => s.display_name === u.speaker_label);
    }
    
    // 2. По u.speaker_id
    if (!speaker && u.speaker_id) {
        speaker = speakers.find(s => s.id === u.speaker_id);
    }
    
    // 3. Виртуальный speaker со стабильным цветом
    if (!speaker && (u.speaker_id || u.speaker_label)) {
        const colors = ['#3b82f6', '#ef4444', '#10b981', '#f59e0b'];
        speakerColor = colors[hash(idStr) % colors.length];
    }
}
```
