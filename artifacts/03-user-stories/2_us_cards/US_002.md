# US-002: Загрузка файла по HTTPS-ссылке из облака

| Поле | Значение |
|---|---|
| **ID** | US-002 |
| **Эпик** | EPIC-FILE |
| **Приоритет** | Must |
| **Story Points** | 5 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | UploadForm |
| **API** | POST /api/v1/transcribe/from-url |

## User Story
**Как** Алексей (P-01),
**я хочу** вставить HTTPS-ссылку на файл из Яндекс.Диска / Google Drive / Mail.ru и получить протокол,
**чтобы** не скачивать файл вручную.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — шаг 1 (загрузка файла).
- **Боль персоны:** «Файл лежит в облаке, скачивать вручную + потом загружать — двойная работа».
- **Связь с Vision:** §7.1 Базовое ядро — «Загрузка файла по ссылке из облака».

## Acceptance Criteria

- **AC-1:** Given я на странице загрузки, When я вставляю HTTPS-ссылку в поле «Ссылка из облака» и нажимаю «Загрузить», Then файл скачивается потоково (chunk ≤8 МБ) на локальный диск, появляется протокол со статусом «Загружен».

- **AC-2:** Given ссылка ведёт на публичный файл, When идёт загрузка, Then я вижу прогресс-бар (скачано X из Y МБ).

- **AC-3:** Given ссылка требует авторизации (приватный файл Google Drive), When я вставляю ссылку, Then я вижу сообщение «Файл недоступен. Сделайте ссылку публичной или используйте загрузку файла».

- **AC-4:** Given сертификат HTTPS невалиден (самоподписанный), When идёт загрузка, Then я вижу экран подтверждения «Сертификат невалиден. Продолжить загрузку? Это может быть небезопасно» с кнопками «Да, продолжить» / «Отмена».

- **AC-5:** Given Content-Length > 2 ГБ, When начинается загрузка, Then я вижу предупреждение «Файл большой, обработка может занять X минут и потребует до 4 ГБ RAM. Продолжить?».

- **AC-6:** Given скачивание прервалось (сеть упала), When я снова открываю приложение, Then загрузка автоматически возобновляется с того же места (HTTP Range) или предлагается «Начать заново».

## Технические заметки
- Поддерживаемые источники: Яндекс.Диск (публичные ссылки), Google Drive (публичные), Mail.ru (публичные), Dropbox (публичные).
- HTTP Range для докачки.
- Таймаут на скачивание: 30 минут (после — отмена с сообщением).
- Проверка Content-Type должен соответствовать аудио/видео.

## Связанные артефакты
- Vision: §7.1 Базовое ядро
- Persona: P-01 Алексей (Windows)
- Risk: #7 Загрузка большого файла по HTTPS «съедает» RAM
- Допущение: HTTPS-сертификат доступен (для самоподписанных — отдельный экран подтверждения)
