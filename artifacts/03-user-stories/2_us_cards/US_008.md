# US-008: Сохранение изменений в транскрипте (правка текста реплик)

| Поле | Значение |
|---|---|
| **ID** | US-008 |
| **Эпик** | EPIC-TRANS |
| **Приоритет** | Must |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows), P-03 Гость |
| **Форма** | ProtocolView → TranscriptTab |
| **API** | PATCH /api/v1/transcripts/{protocol_id}/replicas/{replica_id} |

## User Story
**Как** Алексей (P-01),
**я хочу** кликнуть на любую реплику в транскрипции, исправить опечатки Whisper и сохранить изменения,
**чтобы** итоговый протокол был чистым без перезапуска транскрипции.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — шаг «Правка транскрипции» (после US-005/US-007).
- **Боль персоны:** «Whisper написал "Генадий" вместо "Геннадий" — хочу поправить и сохранить, чтобы DOCX был без ошибок».
- **Боль P-03:** «Если в моей реплике ошибка — я прошу Алексея поправить; хочу быть уверен, что правки сохраняются».
- **Связь с Vision:** §7.1 — «Правка реплик»; вклад в WER KPI.

## Acceptance Criteria

- **AC-1:** Given я открыл транскрипцию, When я кликаю на текст реплики, Then текст становится редактируемым (contenteditable / textarea), появляется кнопка «Сохранить» и «Отмена».

- **AC-2:** Given я отредактировал текст, When я нажимаю «Сохранить» (или Ctrl+Enter), Then изменения сохраняются в БД (`replicas.text` обновляется), иконка реплики получает метку «изменено» (деловая иконка карандаша, см. US-068).

- **AC-3:** Given я редактирую реплику, When я нажимаю «Отмена» (или Esc), Then исходный текст восстанавливается, изменения не сохраняются.

- **AC-4:** Given правка сохранена, When я перезагружаю страницу протокола, Then я вижу отредактированный текст (не «сырой» Whisper).

- **AC-5:** Given я редактирую несколько реплик подряд, When все правки сделаны, Then я могу нажать «Сохранить все» (batch save) — один PATCH-запрос с массивом изменений.

- **AC-6:** Given я редактировал реплику, When я нажимаю «Откатить к оригиналу», Then текст возвращается к Whisper-варианту (хранится в `replicas.text_original`), метка «изменено» снимается.

- **AC-7:** Given backend недоступен, When я нажимаю «Сохранить», Then я вижу ошибку «Не удалось сохранить. Проверьте соединение» и текст остаётся в режиме редактирования (правка не теряется).

## Технические заметки
- Хранение: `replicas.text_original` (от Whisper), `replicas.text` (текущий, после правок), `replicas.is_edited` (bool).
- Optimistic update на фронте + rollback при ошибке.
- Debounce 1.5 сек для автосохранения (опционально, по настройке).
- История правок (опционально): `replica_edits (replica_id, old_text, new_text, edited_at, edited_by)`.
- Логирование в audit log (US-042).
