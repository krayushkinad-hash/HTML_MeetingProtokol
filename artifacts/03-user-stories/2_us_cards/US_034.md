# US-034: Email-уведомления (опциональный канал)

## User Story
**Как** Алексей (P-01),
**я хочу** получать email-уведомления о завершении обработки протокола как альтернативу push,
**чтобы** быть в курсе даже если браузер закрыт или я не онлайн.

## Контекст
- **Процесс:** Уведомления (параллельно с US-033 push).
- **Боль персоны:** «Push не всегда доходят (например, Firefox без разрешения). Email — надёжный fallback».
- **Связь с Vision:** §7.1 — Email-уведомления (опционально).
- **Допущение:** SMTP настраивается пользователем (свой сервер/Gmail/Yandex), по умолчанию выключено.

## Acceptance Criteria

- **AC-1:** Given я открываю Настройки → Уведомления → Email, When страница загружена, Then я вижу форму: «SMTP host», «Port», «Username», «Password», «From address», «To address», чекбокс «Включить email-уведомления».

- **AC-2:** Given я заполнил SMTP-настройки, When я нажимаю «Отправить тестовое письмо», Then я получаю письмо «Test from HTML_MeetingProtokol» на указанный адрес, в UI — зелёная плашка «Письмо отправлено успешно».

- **AC-3:** Given email-уведомления включены, When транскрипция завершается, Then я получаю письмо:
  - Тема: «[HTML_MeetingProtokol] Транскрипция готова»
  - Тело: название протокола, длительность, дата, ссылка «Открыть протокол»

- **AC-4:** Given я не хочу спама, When я выбираю в настройках, Then я могу настроить частоту: «Только критические (ошибки)» / «Все завершения» / «Отключить».

- **AC-5:** Given SMTP-сервер недоступен, When я пытаюсь отправить тестовое письмо, Then я вижу ошибку «Не удалось подключиться к SMTP-серверу: <details>».

- **AC-6:** Given я не хочу хранить пароль в открытом виде, When я сохраняю настройки, Then пароль шифруется (Fernet/AES), хранится в зашифрованном виде в БД.

- **AC-7:** Given я в Astra Linux офлайн, When я пытаюсь отправить тестовое письмо, Then я вижу «Email требует подключения к интернету для отправки через внешний SMTP».

## Технические заметки
- Библиотека: `aiosmtplib` (async SMTP клиент).
- Шифрование пароля: `cryptography.Fernet` с ключом из `.env` (`ENCRYPTION_KEY`).
- TLS: обязательно (порт 587 с STARTTLS или 465 с SSL).
- Шаблоны писем: Jinja2 → HTML + plain text версия.
- Throttling: не чаще 1 письма в 5 мин на пользователя.
- Альтернатива: локальный SMTP (mbox формат) для полностью офлайн-сценариев — out of scope.
