# US-014: Фильтр по дате в списке протоколов

| Поле | Значение |
|---|---|
| **ID** | US-014 |
| **Эпик** | EPIC-HISTORY |
| **Приоритет** | Must |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows), P-02 Алексей (Astra, офлайн) |
| **Форма** | ProtocolListView (filter toolbar) |
| **API** | GET /api/v1/protocols?date_from=&date_to= |

## User Story
**Как** Алексей (P-01),
**я хочу** отфильтровать список протоколов по диапазону дат (за неделю / за месяц / произвольный период),
**чтобы** быстро найти нужную встречу, не листая сотни строк.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — шаг «Найти нужный протокол».
- **Боль персоны:** «У меня 200 протоколов — без фильтра листать долго. Хочу "за прошлую неделю" или "за октябрь"».
- **Боль P-02:** «В командировке хочу быстро открыть протоколы за последние 3 дня».
- **Связь с Vision:** §7.1 — «Фильтр по дате»; §5 Преимущество #3 «Хронологическая база».

## Acceptance Criteria

- **AC-1:** Given я на странице списка протоколов, When я выбираю пресет «Сегодня» / «Последние 7 дней» / «Последние 30 дней» / «Прошлый месяц», Then список мгновенно фильтруется, счётчик показывает «Найдено: N протоколов».

- **AC-2:** Given мне нужен произвольный диапазон, When я нажимаю «Свой диапазон…» и выбираю даты «от» и «до» через datepicker, Then список фильтруется по выбранному периоду.

- **AC-3:** Given фильтр применён, When я смотрю на URL, Then параметры `date_from` и `date_to` сохранены в query string (можно поделиться ссылкой).

- **AC-4:** Given я применил фильтр, When я нажимаю «Сбросить», Then возвращаются все протоколы (фильтр очищается).

- **AC-5:** Given у меня 200 протоколов, When фильтр установлен на «Сегодня», Then результат возвращается за ≤1 сек (KPI).

- **AC-6:** Given я в Astra Linux офлайн, When я применяю фильтр, Then всё работает через IndexedDB, без обращения к серверу.

## Технические заметки
- Backend: SQL `WHERE meeting_date BETWEEN date_from AND date_to`, индекс по `meeting_date`.
- Frontend: datepicker (vanilla JS, без jQuery — `<input type="date">`).
- Пресеты: вычисляются динамически (текущая дата − N дней).
- Параметры фильтра в URL сохраняются через `history.pushState`.
