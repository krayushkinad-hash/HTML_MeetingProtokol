## User Story
**Как** Алексей (P-01),
**я хочу** видеть современный деловой интерфейс с иконками Material Design (outline style) вместо эмодзи,
**чтобы** приложение выглядело профессионально для делового использования.

## Контекст
- **Процесс:** Использование приложения.
- **Боль персоны:** «Эмодзи — несерьёзно для бизнес-инструмента».
- **Связь с Vision:** §8 Design System v1.

## Acceptance Criteria

- **AC-1:** Given открыт frontend, When пользователь видит UI, Then нет эмодзи (📅, 📁, и т.п.) в production-коде.

- **AC-2:** Given все иконки, When они показаны, Then они Material Design outline style — единый стиль.

- **AC-3:** Given кнопки, badges, статусы, When они видны, Then у них иконки 16px или 20px в линейном стиле.

- **AC-4:** Given навигация (Протоколы, Календарь, Загрузить, Live, Настройки), When пользователь смотрит navbar, Then каждая вкладка имеет деловую SVG иконку.

- **AC-5:** Given табы протокола (Транскрипция, Скриншоты, Решения, Задачи, Саммари, Ораторы), When показываются, Then у каждого своя иконка.

- **AC-6:** Given статус протокола (loaded, transcribing, ready), When показывается badge, Then используется цветовая схема вместо эмодзи 🟢🟡.

## Технические заметки
- Источник иконок: Google Material Icons (open source, MIT)
- Inline SVG для ускорения загрузки
- Все иконки в `views/components/icons.js`
- SVG paths из официального Material Symbols
