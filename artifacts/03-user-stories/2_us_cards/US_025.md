# US-025: Настраиваемые шаблоны DOCX-экспорта

| Поле | Значение |
|---|---|
| **ID** | US-025 |
| **Эпик** | EPIC-DOCX |
| **Приоритет** | Should |
| **Story Points** | 5 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | SettingsPage → TemplatesTab, ExportDialog (template chooser) |
| **API** | GET/POST /api/v1/templates |

## User Story
**Как** Алексей (P-01),
**я хочу** выбрать шаблон DOCX перед экспортом (Стандарт / Краткий / Подробный / Мой) и настроить, какие секции включать,
**чтобы** получать разные форматы протоколов для разных аудиторий (заказчик vs команда vs архив).

## Контекст
- **Процесс:** Этап «Экспорт результата» — выбор формата перед генерацией.
- **Боль персоны:** «Заказчику — короткий протокол без транскрипции. Команде — подробный с таймкодами. Архиву — со скриншотами. Хочу переключать, а не генерировать каждый раз заново».
- **Связь с Vision:** §7.1 — «DOCX-экспорт: настраиваемые шаблоны»; расширение US-015/US-024.
- **KPI:** Экономия времени ≥30% при повторных экспортах.

## Acceptance Criteria

- **AC-1:** Given я открываю диалог экспорта, When он показан, Then я вижу выпадающий список шаблонов: «Стандартный (Краюшкин)» / «Краткий (только саммари+задачи+решения)» / «Подробный (полная транскрипция)» / «Пользовательские».

- **AC-2:** Given я выбрал шаблон «Стандартный», When я нажимаю «Экспортировать», Then DOCX содержит: титул, участники, саммари, задачи, решения, транскрипция с таймкодами, скриншоты — всё в порядке разделов стандартного шаблона.

- **AC-3:** Given я выбрал шаблон «Краткий», When идёт экспорт, Then DOCX содержит только: титул, участники, саммари, задачи, решения. Транскрипция и скриншоты не включаются.

- **AC-4:** Given я хочу создать свой шаблон, When я открываю Настройки → Шаблоны DOCX и нажимаю «+ Новый шаблон», Then я вижу конструктор: чекбоксы секций (титул/саммари/транскрипция/задачи/решения/скриншоты), настройка порядка, выбор шрифта (TNR/Arial/Calibri), полей страницы, цвет заголовков.

- **AC-5:** Given я создал шаблон «Для заказчика», When я сохраняю его под именем, Then он появляется в списке шаблонов при следующем экспорте.

- **AC-6:** Given у меня 5 пользовательских шаблонов, When я хочу редактировать один, Then я нажимаю «Изменить», меняю настройки, сохраняю — изменения применяются к следующим экспортам.

- **AC-7:** Given я хочу сбросить шаблон к defaults, When я нажимаю «Сбросить к стандартному», Then все настройки шаблона возвращаются к исходным (подтверждение через диалог).

## Технические заметки
- Шаблон = JSON-конфиг: `{sections: [...], font: "TNR", margins: {...}, colors: {...}}`.
- Хранение: `templates (id, user_id, name, config_json, is_default, created_at)`.
- Предустановленные шаблоны: «Стандартный (Краюшкин)», «Краткий», «Подробный».
- Расширяемость: можно добавить «HTML-шаблон» (US-035 — шаринг через ссылку) с тем же config.
- Версионирование: каждый экспорт сохраняет ID шаблона для воспроизводимости.
