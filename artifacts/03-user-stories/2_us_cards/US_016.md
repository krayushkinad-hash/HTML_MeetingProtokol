# US-016: Встраивание скриншотов экрана в DOCX

| Поле | Значение |
|---|---|
| **ID** | US-016 |
| **Эпик** | EPIC-DOCX |
| **Приоритет** | Should |
| **Story Points** | 8 |
| **Персона** | P-01 Алексей (Windows) |

| **API** | POST /api/v1/export/docx?screenshots=true |

## User Story
**Как** Алексей (P-01),
**я хочу**, чтобы в DOCX были встроены скриншоты экрана демонстранта с привязкой к моменту реплики,
**чтобы** участники видели, что показывалось в момент обсуждения (слайды, схемы, код).

## Контекст
- **Процесс:** «Экспорт DOCX» — этап «Подготовка протокола».
- **Боль персоны:** «На технических встречах 50% контекста — это код/схемы на экране. Без скриншотов протокол теряет смысл».
- **Связь с Vision:** §7.1 «Экспорт DOCX со скриншотами» + «Онлайн-режим: захват видеопотока + скриншотов экрана демонстранта».
- **Зависимость:** US-021 (захват скриншотов во время встречи).

## Acceptance Criteria

- **AC-1:** Given в настройках экспорта включена опция «Включить скриншоты», When я экспортирую, Then в DOCX после реплики, во время которой был сделан скриншот, встроено изображение (jpg/png).

- **AC-2:** Given скриншот встроен, When я смотрю DOCX, Then под изображением — подпись «Рисунок N. Скриншот экрана в момент реплики [Имя оратора] в HH:MM:SS».

- **AC-3:** Given размер скриншота больше ширины страницы, When изображение встраивается, Then оно масштабируется до 15 см по ширине (max), сохраняя пропорции.

- **AC-4:** Given в протоколе 30 скриншотов, When идёт экспорт, Then итоговый размер DOCX ≤50 МБ (иначе — предупреждение «Файл большой, рекомендуем отправить через облако, а не email»).

- **AC-5:** Given у меня нет скриншотов (офлайн-обработка без онлайн-режима), When я экспортирую с включённой опцией скриншотов, Then опция автоматически отключается и в DOCX нет блока «Скриншоты» — без ошибок.

- **AC-6:** Given скриншот сделан в режиме демонстрации экрана, When он встраивается, Then на нём видна временная метка (таймкод) — для однозначности, какой это момент.

## Технические заметки
- Изображения хранятся в `~/.html_mp/protocols/<id>/screenshots/<HH-MM-SS>.png`.
- Формат: PNG (lossless), разрешение исходное (или 1920×1080 max).
- В DOCX используется `add_picture(path, width=Cm(15))` — высота подгоняется автоматически.
- Подпись через `add_figure_caption_below` (стиль «Подпись», SEQ-поле для автонумерации).
- Сжатие: если DOCX >50 МБ — опционально сжимать в JPEG (quality=85) с предупреждением.
