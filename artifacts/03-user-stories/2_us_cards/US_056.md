# US-056: Настройки AI провайдера

| Поле | Значение |
|---|---|
| **ID** | US-056 |
| **Эпик** | EPIC-SETTINGS |
| **Приоритет** | Must |
| **Story Points** | 2 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | SettingsPage → AITab |
| **API** | GET/PATCH /api/v1/hmp/user-setting |

## User Story
**Как** Алексей (P-01),
**я хочу** выбрать AI провайдер (Hermes/GigaChat/Ollama) и задать API ключи,
**чтобы** саммари и AI-функции работали через выбранный сервис.

## Контекст
- **Процесс:** Настройка AI функций после установки.
- **Боль персоны:** «Хочу свой провайдер, не по умолчанию».
- **Связь с Vision:** §7.1 Базовое ядро — «LLM саммари».

## Acceptance Criteria

- **AC-1:** Given я открыл «Настройки → AI провайдер», When загружается страница, Then отображается выпадающий список: Hermes, GigaChat, Ollama.

- **AC-2:** Given я выбрал «Hermes» как основной провайдер, When сохраняю, Then саммари использует Hermes API.

- **AC-3:** Given я задал fallback провайдер «GigaChat», When Hermes недоступен, Then система автоматически переключается на GigaChat.

- **AC-4:** Given я ввел API ключи в textarea, When сохраняю, Then они шифруются и безопасно сохраняются в БД.

- **AC-5:** Given API ключ неверный, When я пытаюсь сделать саммари, Then я вижу ошибку «Authentication failed» в UI.

## Технические заметки
- Hermes — рекомендуемый по умолчанию (Vision §7.1)
- GigaChat — российский fallback
- Ollama — локальный (нужен Docker)
- API ключи хранятся зашифрованными (ADR-006)
- Формат ключей: KEY=value, по одному на строку
