# US-059: Создание папок для протоколов

| Поле | Значение |

| **ID** | US-059 |

| **API** | POST /api/v1/hmp/folders |

## User Story
**Как** Алексей (P-01),
**я хочу** создавать папки для группировки протоколов,
**чтобы** структурировать встречи по проектам, командам или любой другой логике.

## Контекст
- **Процесс:** Организация рабочего пространства при накоплении протоколов.
- **Боль персоны:** «Когда много протоколов, сложно найти нужный».
- **Связь с Vision:** §7.1 Базовое ядро — «Локальная работа с данными».
- **Отличие от тегов (US-025):** Папки — взаимно исключающие (протокол в одной папке), теги — произвольные (протокол с несколькими).

## Acceptance Criteria

- **AC-1:** Given я на странице «Протоколы», When я нажимаю «+» в сайдбаре папок, Then появляется диалог «Название папки» с полем ввода.

- **AC-2:** Given я ввёл имя «Q4 2026 Встречи» и нажал «OK», Then создаётся запись в БД, папка появляется в сайдбаре, Toast «Папка создана».

- **AC-3:** Given я ввёл пустое имя, When я нажимаю «OK», Then диалог не закрывается, появляется валидация.

- **AC-4:** Given папка создана, When я нажимаю на неё, Then список протоколов фильтруется по этой папке.

- **AC-5:** Given я создал 5 папок, When я открываю страницу, Then все они отображаются в сайдбаре с их цветом и количеством протоколов.

## Технические заметки
- Backend: POST /folders с полями name, color, icon
- Папка по умолчанию: color="#3b82f6", icon="folder"
- Single-user pattern — все папки глобальные
- Возможны вложенные папки (parent_id)
