# US-071: Замена иконок на Font Awesome деловой стиль

| Поле | Значение |
|---|---|

| **Эпик** | EPIC-FRONTEND |
| **Приоритет** | Should |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | Все UI компоненты |
| **API** | — (только UI) |

## User Story
**Как** Алексей (P-01),
**я хочу** чтобы все иконки были в едином профессиональном стиле Font Awesome,
**чтобы** UI выглядел цельно и современно.

## Контекст
- **Процесс:** Использование приложения.
- **Боль персоны:** «Текущие SVG иконки иногда отличаются по толщине/стилю».
- **Связь с Vision:** §8 Design System (US-068) — единая иконочная система.

## Acceptance Criteria

- **AC-1:** Given все иконки в приложении, When они отрисовываются, Then они из Font Awesome Free 6.x (regular/outline style).

- **AC-2:** Given проект подключает Font Awesome, When страница загружается, Then CDN загружает файлы за <100ms (кэшируется).

- **AC-3:** Given все иконки имеют одинаковые размеры (14px, 16px, 20px), Then они выглядят однородно по стилю.

- **AC-4:** Given используется `<i class="fa-solid fa-folder">` syntax, When разработчик добавляет новую иконку, Then это занимает 5 секунд без дополнительных файлов.

## Технические заметки

### Подключение Font Awesome (CDN)

В `index.html`:
```html
<link href="https://cdnjs.cloudflare.com/ajax/libs/font-awesome/6.5.1/css/all.min.css" rel="stylesheet">
```

### Использование в HTML

```html
<!-- Outlined (regular) - деловой стиль -->
<i class="fa-regular fa-folder"></i>
<i class="fa-regular fa-file"></i>
<i class="fa-regular fa-calendar"></i>

<!-- Solid - для важных действий -->
<i class="fa-solid fa-play"></i>
<i class="fa-solid fa-stop"></i>
<i class="fa-solid fa-trash"></i>

<!-- Brands - бренды -->
<i class="fa-brands fa-telegram"></i>
```

### Замена SVG иконок

| Было | Стало |
|---|---|
| `<svg>...</svg>` для каждой | `<i class="fa-folder"></i>` |
| Inline paths | Font Awesome font |
| 32 кастомных | 7000+ готовых FA |

### CSS стратегия

```css
.fa-folder, .fa-folder-open {
    color: #3b82f6;
}
.fa-trash, .fa-trash-can {
    color: #dc2626;
}
.fa-calendar, .fa-clock {
    color: #6b7280;
}

/* Размеры */
.fa-14 { font-size: 14px; }
.fa-16 { font-size: 16px; }
.fa-20 { font-size: 20px; }

/* Outline стиль - деловой */
i.fa-regular { font-weight: 400 !important; }
```

### Удалить `icons.js`

После миграции файл `views/components/icons.js` больше не нужен — Font Awesome имеет все нужные иконки.
