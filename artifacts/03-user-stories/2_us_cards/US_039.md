## User Story
**Как** Алексей (P-01),
**я хочу** настроить Hermes Agent как основной LLM-провайдер для всех AI-функций (саммари, задачи, решения, автотеги, корректировка текста),
**чтобы** получать качественные результаты на русском языке от проверенной модели.

## Контекст
- **Процесс:** Настройка AI-фичей (одноразовая).
- **Боль персоны:** «Хочу один ключ — и чтобы все AI-функции работали. Hermes Agent — мой выбор, потому что хорошо работает с русским и доступен по API».
- **Связь с Vision:** §7.5 — «Hermes Agent как primary LLM»; §6 Цель #6.
- **KPI:** Latency саммари ≤10 сек для 2-часовой встречи.

## Acceptance Criteria

- **AC-1:** Given я открываю Настройки → AI провайдер, When страница загружена, Then карточка Hermes Agent помечена как «⭐ Primary» и содержит поля:
  - «API Key» (от Hermes Agent dashboard)
  - «Base URL» (по умолчанию `https://api.hermes-agent.example.com/v1`)
  - «Model» (по умолчанию `hermes-agent-pro`)
  - Чекбокс «Включить как primary»
  - Кнопка «Проверить подключение»

- **AC-2:** Given я ввёл API Key и Base URL, When я нажимаю «Проверить», Then backend делает тестовый запрос `chat/completions` с промптом «Ответь одним словом: ок», я вижу зелёную плашку «Hermes Agent: подключение успешно, модель: hermes-agent-pro».

- **AC-3:** Given Hermes Agent включён как primary, When я запускаю саммари/задачи/решения/автотеги, Then ВСЕ AI-фичи идут через Hermes Agent.

- **AC-4:** Given Hermes Agent возвращает ошибку (timeout / 5xx / 401), When основной провайдер недоступен, Then система автоматически переключается на fallback (GigaChat, затем Ollama — см. US-038, US-040).

- **AC-5:** Given запрос содержит чувствительные данные, When я хочу отключить отправку в облако, Then я могу выключить Hermes Agent в настройках, AI-фичи переходят на Ollama (offline).

- **AC-6:** Given я использую Hermes Agent, When я смотрю в footer progress-bar, Then вижу «🤖 Hermes Agent (primary)».

- **AC-7:** Given несколько AI-функций работают параллельно (саммари + задачи), When идёт обработка, Then каждый запрос rate-limited отдельно (≤10 RPM для Hermes по умолчанию), без конфликтов.

## Технические заметки
- OpenAI-совместимый API: `POST {base_url}/chat/completions` с заголовком `Authorization: Bearer {api_key}`.
- Поддержка JSON mode: `response_format: {type: "json_object"}` для структурированных ответов.
- Библиотека: `openai` (Python SDK совместим с Hermes Agent).
- Таймаут: 60 сек для саммари (большие чанки), 30 сек для задач.
- Retry: 2 попытки при 5xx/timeout, без retry при 4xx (кроме 429).
- Стоимость: зависит от тарифа Hermes Agent (нужно вписать).
