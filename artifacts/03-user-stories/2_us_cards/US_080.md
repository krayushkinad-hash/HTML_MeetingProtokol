# US-080 — Heartbeat прогресс при транскрипции

**Epic:** US-005 — Транскрипция (US-066 In-memory progress tracking)
**Priority:** High
**Status:** Done (2026-09-22)
**Effort:** 1 SP

## User Story

> Как **пользователь**, я хочу **видеть живой прогресс во время транскрипции** (не только 0% и 100%), чтобы **понимать что процесс работает**, а не завис.

## Acceptance Criteria

- [x] Heartbeat обновляет `status.message` каждые 2 сек
- [x] Показывает прошедшее время: "Обработка аудио... 30с"
- [x] Heartbeat останавливается при завершении (`stop_heartbeat.set()`)
- [x] Heartbeat останавливается при исключении (try/finally)
- [x] Heartbeat НЕ обновляет progress_percent (только message)
- [x] Heartbeat НЕ трогает БД (только in-memory)

## Technical Details

### Heartbeat (app/services/transcription.py)

```python
stop_heartbeat = asyncio.Event()
transcribe_start_time = time.time()

async def heartbeat_progress():
    """Update progress message while transcription is running.

    E113-fix: НЕ обновляет progress_percent (это делает progress_cb).
    Только обновляет message — чтобы UI знал, что процесс жив.
    """
    while not stop_heartbeat.is_set():
        elapsed = time.time() - transcribe_start_time
        # Show real elapsed in message — but DO NOT touch progress_percent
        status.message = f"Обработка аудио... {int(elapsed)}с"
        try:
            await asyncio.wait_for(stop_heartbeat.wait(), timeout=2.0)
        except asyncio.TimeoutError:
            pass

heartbeat_task = asyncio.create_task(heartbeat_progress())
```

### Stop heartbeat (try/finally)

```python
try:
    segments_list, info = await asyncio.to_thread(_run_transcribe_eager)
    status.progress_percent = 100
    status.status = "completed"
    status.wer_quality = 0.0
finally:
    # E113-fix: heartbeat всегда останавливается (даже при исключении)
    stop_heartbeat.set()
    try:
        await asyncio.wait_for(heartbeat_task, timeout=2.0)
    except asyncio.TimeoutError:
        heartbeat_task.cancel()
        try:
            await heartbeat_task
        except asyncio.CancelledError:
            pass
```
