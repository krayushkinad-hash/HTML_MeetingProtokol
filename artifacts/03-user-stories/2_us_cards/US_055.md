# US-055: Настройки параметров транскрипции

| **Приоритет** | Must |

| **Форма** | SettingsPage → TranscriptionTab |
| **API** | GET/PATCH /api/v1/hmp/user-setting |

## User Story
**Как** Алексей (P-01),
**я хочу** настроить модель Whisper, язык и использование GPU,
**чтобы** транскрипция была оптимальной для моего оборудования и языка встреч.

## Контекст
- **Процесс:** Первоначальная настройка после установки.
- **Боль персоны:** «Транскрипция медленная, занимает всю память».
- **Связь с Vision:** §7.1 Базовое ядро — «Локальная транскрипция через Whisper».

## Acceptance Criteria

- **AC-1:** Given я открыл «Настройки → Транскрипция», When загружается страница, Then отображается выпадающий список моделей: tiny, base, small, medium, large-v3.

- **AC-2:** Given я выбрал модель «large-v3», When я нажимаю «💾 Сохранить», Then модель сохраняется и используется при следующей транскрипции.

- **AC-3:** Given я выбрал язык «Русский», When сохраняю, Then все новые транскрипции используют этот язык.

- **AC-4:** Given я включил «Использовать GPU», When сохраняю, Then следующие транскрипции используют CUDA.

- **AC-5:** Given у меня нет GPU, When я включаю «Использовать GPU», Then при следующей транскрипции Backend вернёт предупреждение «GPU не обнаружен, используется CPU».

## Технические заметки
- Whisper Large-v3 = ~3 ГБ RAM, лучшее качество
- Whisper Tiny = ~1 ГБ RAM, быстро
- GPU ускоряет в 5-10 раз
- Язык «auto» — модель определяет автоматически
