# US-072: Удаление всех данных из Настроек

| Поле | Значение |
|---|---|
| **ID** | US-072 |
| **Эпик** | EPIC-SETTINGS |
| **Приоритет** | Should |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | SettingsPage → DataTab (кнопка "Удалить всё") |
| **API** | DELETE /api/v1/hmp/admin/clear-data |

## User Story
**Как** Алексей (P-01),
**я хочу** удалить все данные (протоколы, файлы, настройки) одной кнопкой из настроек,
**чтобы** быстро очистить систему для нового использования.

## Контекст
- **Процесс:** Передача приложения новому пользователю / тестовая очистка.
- **Боль персоны:** «Удалять каждый протокол по одному долго — хочу одной кнопкой».
- **Связь с Vision:** §7 «Хранение данных».

## Acceptance Criteria

- **AC-1:** Given я открыл Settings → Data, When я нажимаю "Удалить все данные", Then показывается предупреждение с количеством протоколов и файлов.

- **AC-2:** Given я подтвердил удаление, Then:
  - Все протоколы удаляются из БД
  - Все файлы удаляются с диска
  - Папка `~/.html_mp/` очищается
  - Toast: "Удалено протоколов: N, файлов: M"

- **AC-3:** Given я передумал, When я нажимаю "Отмена" или закрываю окно, Then данные остаются.

- **AC-4:** После очистки, Given я открываю приложение, Then список протоколов пуст, настройки сброшены к defaults.

## Технические заметки

### Только для разработки/dev!

В production это должно быть ограничено или вообще недоступно. Для простого desktop-приложения — нет смысла скрывать.

### Endpoint

`DELETE /api/v1/hmp/admin/clear-data`:
- Удаляет ВСЕ записи из таблиц
- Удаляет ВСЮ папку `protocols/`
- Сбрасывает `user_setting` к defaults
- Возвращает статистику

### UI компонент

```html
<button class="btn btn-danger">
  <i class="fa-solid fa-trash-can"></i>
  Удалить все данные
</button>
```

С двумя confirm-диалогами (защита от случайного клика).
