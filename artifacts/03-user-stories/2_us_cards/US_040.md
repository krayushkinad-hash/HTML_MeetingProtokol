# US-040: Ollama локальный — offline режим LLM

## User Story
**Как** Алексей (P-01),
**я хочу** настроить локальный Ollama как LLM-провайдер для полностью офлайн-режима,
**чтобы** AI-функции (саммари, задачи) работали даже без интернета и без отправки данных в облако.

## Контекст
- **Процесс:** Настройка AI-фичей (для приватности / офлайна).
- **Боль персоны:** «Hermes Agent отправляет данные в облако — для конфиденциальных встреч это недопустимо. Ollama локально = полная приватность».
- **Боль P-02:** «В Astra Linux офлайн — облачные провайдеры не работают, нужен локальный».
- **Связь с Vision:** §7.5 — Ollama offline; §8 Risk #4 (отправка данных в облако).
- **KPI:** Latency Ollama (CPU) ≤60 сек для саммари 2-часовой встречи.

## Acceptance Criteria

- **AC-1:** Given я установил Ollama локально (`ollama serve`), When я открываю Настройки → AI провайдер, Then я вижу карточку Ollama с полями:
  - «Base URL» (по умолчанию `http://localhost:11434`)
  - «Model» (по умолчанию `llama3.1:8b-instruct-q5_K_M`, опции — qwen2.5, mistral)
  - Чекбокс «Включить как offline fallback»
  - Кнопка «Проверить подключение»

- **AC-2:** Given я ввёл Base URL и нажал «Проверить», When backend делает `GET /api/tags`, Then я вижу список доступных моделей + зелёная плашка «Ollama: подключение успешно, X моделей доступно».

- **AC-3:** Given Ollama включена как offline fallback, When Hermes Agent и GigaChat недоступны (нет сети), Then система автоматически переключается на Ollama, AI-функции работают локально.

- **AC-4:** Given я использую Ollama, When я смотрю footer progress-bar, Then вижу «🤖 Ollama (local, offline)» — это явный индикатор, что данные НЕ уходят в облако.

- **AC-5:** Given Ollama-сервер не запущен, When я пытаюсь сгенерировать саммари, Then я вижу ошибку «Ollama недоступна. Запустите `ollama serve` в терминале или отключите offline fallback в настройках».

- **AC-6:** Given я выбрал модель, которая не скачана, When backend делает первый запрос, Then Ollama автоматически скачивает модель (`ollama pull`), в UI виден прогресс «Скачивание модели... 50%» (один раз).

- **AC-7:** Given Ollama работает, When я в Astra Linux без сети (P-02), Then саммари/задачи работают, всё в локальной сети, без внешних запросов.

- **AC-8:** Given Ollama работает в Astra Linux (P-02), When модель требует GPU, но GPU нет, Then автоматически используется CPU-режим (медленнее, но работает).

## Технические заметки
- Ollama API: OpenAI-совместимый (`POST /v1/chat/completions`) начиная с v0.5+.
- Модели: `llama3.1:8b-instruct-q5_K_M` (~5 ГБ), `qwen2.5:7b-instruct`, `mistral:7b-instruct` — поддерживают русский.
- Производительность: на CPU (i7-12700) — ~10 токенов/сек, на GPU (RTX 3060) — ~50 токенов/сек.
- Embedding-модели: `nomic-embed-text` или `mxbai-embed-large` для семантического поиска (US-013).
- Мониторинг: `GET /api/ps` — какие модели сейчас загружены в память.
