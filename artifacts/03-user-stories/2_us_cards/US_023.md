# US-023: Извлечение Action Items (задач) из транскрипции

| Поле | Значение |
|---|---|

| **Эпик** | EPIC-AI |
| **Приоритет** | Must |

| **API** | POST /api/v1/llm/extract-tasks/{protocol_id} |

## User Story
**Как** Алексей (P-01),
**я хочу** после встречи получить автоматически извлечённый список задач (Action Items): кто, что, к какому сроку должен сделать,
**чтобы** не выписывать задачи вручную и сразу перенести их в таск-трекер.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — параллельно с саммари (US-022).
- **Боль персоны:** «На встрече наговорили 15 задач — записывать не успеваю. После встречи сажусь и полчаса выписываю. Хочу автоматически».
- **Связь с Vision:** §7.1 — «Извлечение Action Items»; §6 Цель #6 «AI-фичи».

## Acceptance Criteria

- **AC-1:** Given транскрипция завершена, When я нажимаю «Извлечь задачи», Then LLM возвращает JSON:
  ```json
  [
    {"assignee": "Иван", "task": "Подготовить PR для миграции БД", "due_date": "2026-10-15", "priority": "high", "replica_id": 12345},
    {"assignee": "Мария", "task": "Согласовать дизайн с заказчиком", "due_date": null, "priority": "medium", "replica_id": 12389}
  ]
  ```

- **AC-2:** Given задачи извлечены, When я открываю вкладку «Задачи», Then я вижу таблицу: «Кто» / «Что» / «Срок» / «Приоритет» / «Действие». Действие: «Открыть в таск-трекере» (ссылка) или «Отметить как сделанное».

- **AC-3:** Given задача содержит таймкод, When я кликаю на «▶ HH:MM:SS» рядом с задачей, Then открывается транскрипция на этой секунде.

- **AC-4:** Given LLM ошибся в assignee, When я редактирую задачу (двойной клик на поле «Кто»), Then я могу исправить имя, изменения сохраняются в БД.

- **AC-5:** Given задач нет (маленькая встреча без action items), When LLM возвращает пустой массив, Then я вижу «Задач не обнаружено. Это была информационная встреча?».

- **AC-6:** Given задачи извлечены, When я нажимаю «Экспорт в Markdown», Then скачивается `.md` файл с чекбоклами (`- [ ] Иван — Подготовить PR — 2026-10-15`) для копирования в Todoist/Notion/Things.

- **AC-7:** Given я хочу экспортировать в JSON, When я нажимаю «Экспорт → JSON», Then скачивается `.json` для интеграции с внешними таск-трекерами.

## Технические заметки
- Промпт: «Извлеки все задачи/действия из транскрипции. Для каждой: исполнитель, формулировка, срок (если упомянут), приоритет (high/medium/low), таймкод исходной реплики».
- Учёт неоднозначностей: если исполнитель не назван явно — `assignee = null` и помечается «Не назначен».
- Дополнительные правила: «отправить», «подготовить», «сделать до…» → признаки задачи.
- Хранение: `action_items (id, protocol_id, assignee, task, due_date, priority, replica_id, is_done, created_at)`.
