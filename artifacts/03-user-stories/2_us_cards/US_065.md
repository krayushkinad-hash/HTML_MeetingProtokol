# US-065: Сохранение настроек с черновиком в localStorage

## User Story
**Как** Алексей (P-01),
**я хочу** чтобы настройки сохранялись **мгновенно** в браузере (черновик) и не терялись при переключении между вкладками,
**чтобы** не вводить заново если я случайно переключился.

## Контекст
- **Процесс:** Настройка приложения.
- **Боль персоны:** «Вводил ключ API, переключился — всё исчезло!»
- **Связь с Vision:** §7.5 UX — современный отзывчивый интерфейс.

## Acceptance Criteria

- **AC-1:** Given я ввёл значение в поле, When я переключаюсь на другую вкладку, Then значение сохраняется в localStorage и при возврате показывается обратно.

- **AC-2:** Given localStorage содержит черновик, When я нажал "Сохранить", Then API запрос выполняется, при успехе — черновик удаляется.

- **AC-3:** Given backend недоступен, When я нажал "Сохранить", Then данные всё равно сохраняются в черновик, появляется Toast "Сохранено локально".

- **AC-4:** Given черновик пуст или устарел, When я открываю настройки, Then показываются данные из API (а не пустые поля).

- **AC-5:** Given я нажимаю "Очистить локальный кэш", When подтверждаю, Then IndexedDB очищается **И** черновик настроек тоже удаляется.

- **AC-6:** Given кнопка "Сохранить" активна, When я нажимаю её, Then она становится disabled с текстом "Сохранение..." до завершения запроса.

## Технические заметки
- Используется `localStorage.setItem('hmp_settings_draft', JSON)`
- При `blur` или `change` поля — сохранение в draft
- При успешном API → `clearDraft()`
- Кнопка показывает состояние сохранения
