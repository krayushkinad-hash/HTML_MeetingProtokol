# US-050: GPU-ускорение транскрипции (CUDA)

## User Story
**Как** Алексей (P-01) (у меня игровой ПК с NVIDIA RTX 3060),
**я хочу** чтобы транскрипция использовала GPU (CUDA) для ускорения в 5–10×,
**чтобы** 2-часовая запись обрабатывалась за 10–15 мин вместо 1–2 часов на CPU.

## Контекст
- **Процесс:** Транскрипция (фоновая операция).
- **Боль персоны:** «Транскрипция на CPU 2 ч аудио = 1.5 ч реального времени. С GPU = 12 мин. Хочу GPU».
- **Связь с Vision:** §7.1 — «GPU-ускорение»; §9 Ресурсы.
- **KPI:** Latency транскрипции 2 ч записи ≤15 мин на GPU vs ≤120 мин на CPU.

## Acceptance Criteria

- **AC-1:** Given я установил CUDA + cuDNN + PyTorch с CUDA-поддержкой, When я открываю Настройки → Транскрипция, Then я вижу секцию «GPU» с автоопределением:
  - GPU: NVIDIA GeForce RTX 3060 (8 ГБ VRAM)
  - CUDA: 12.1
  - cuDNN: 8.9

- **AC-2:** Given GPU определён, When я нажимаю чекбокс «Использовать GPU для транскрипции», Then модель Whisper загружается в VRAM (`model.to('cuda')`), при следующей транскрипции inference идёт на GPU.

- **AC-3:** Given GPU активен, When идёт транскрипция, Then скорость в 5–10× выше (например, `large-v3` на RTX 3060 — ~10× realtime, vs CPU — ~1× realtime).

- **AC-4:** Given VRAM < требуемой (например, выбрана `large-v3` при 4 ГБ VRAM), When я пытаюсь включить GPU, Then появляется ошибка «Недостаточно VRAM. Доступно 4 ГБ, требуется 8 ГБ для large-v3. Используйте medium или отключите GPU».

- **AC-5:** Given GPU включён, When я смотрю footer progress-bar (US-020), Then вижу индикатор «🎮 GPU (RTX 3060, 60% VRAM)».

- **AC-6:** Given GPU активен, When я мониторю ресурсы, Then в UI виден real-time график VRAM и температуры GPU (через `nvidia-smi` или `pynvml`).

- **AC-7:** Given GPU активен, When я хочу освободить VRAM (например, чтобы поиграть), я нажимаю «Выгрузить модель из VRAM», модель выгружается, VRAM освобождается.

- **AC-8:** Given я на CPU-only системе (Astra Linux P-02 без NVIDIA), When я открываю настройки, Then секция «GPU» показывает «GPU не обнаружен. Транскрипция будет на CPU (медленнее)», чекбокс неактивен.

## Технические заметки
- PyTorch: `torch.cuda.is_available()`, `torch.cuda.get_device_name(0)`, `torch.cuda.get_device_properties(0).total_memory`.
- Whisper (faster-whisper): `model = WhisperModel("large-v3", device="cuda", compute_type="float16")`.
- fp16 для экономии VRAM (вдвое меньше, минимальная потеря качества).
- Beam size = 1 для скорости (по умолчанию), beam = 5 для качества (опционально).
- VAD (voice activity detection) фильтрация — снижает время на тишину.
- Мониторинг: `pynvml` или `nvidia-smi --query-gpu=memory.used,utilization.gpu,temperature.gpu --format=csv`.
- Fallback на CPU: если CUDA error → автоматический retry на CPU (см. US-051).
