# US-058 — Whisper Models — VAD параметры

**Epic:** US-005 — Транскрипция
**Priority:** Medium
**Status:** Done (2026-09-22)
**Effort:** 2 SP

## User Story

> Как **администратор системы**, я хочу **настроить чувствительность VAD через config**, чтобы **контролировать обрезку тишины** и не терять речь при шумных аудио.

## Acceptance Criteria

- [x] `whisper_vad_filter: bool` в config.py — включить/выключить VAD
- [x] `vad_min_silence_duration_ms: int = 1000` — минимальная пауза для обрезки
- [x] `vad_speech_pad_ms: int = 300` — padding вокруг речи
- [x] `vad_threshold: float = 0.5` — порог уверенности (0-1)
- [x] Параметры передаются в `faster_whisper` через `vad_parameters`
- [x] Default VAD **OFF** (сохраняем всё аудио)

## Technical Details

### Config (app/core/config.py)

```python
class Settings:
    # E111: VAD удаляет тишину, но иногда удаляет и речь.
    whisper_vad_filter: bool = False

    # E118: VAD параметры (для тонкой настройки чувствительности)
    vad_min_silence_duration_ms: int = 1000
    vad_speech_pad_ms: int = 300
    vad_threshold: float = 0.5
```

### Transcription (app/services/transcription.py)

```python
vad_filter=settings.whisper_vad_filter,
vad_parameters=(
    {
        "min_silence_duration_ms": settings.vad_min_silence_duration_ms,
        "speech_pad_ms": settings.vad_speech_pad_ms,
        "threshold": settings.vad_threshold,
    }
    if settings.whisper_vad_filter
    else None
),
```

## Recommendations

| Use case | VAD | min_silence | threshold |
|---|---|---|---|
| Чистая речь (интервью) | ✅ ON | 500ms | 0.4 |
| Совещание с шумом | ❌ OFF | — | — |
| Подкаст с паузами | ✅ ON | 1000ms | 0.5 |
| Лекция/доклад | ✅ ON | 1500ms | 0.6 |
