# US-083 — Ручная пометка фраз как "Решения" в транскрипте

**Epic:** US-023 — Управление решениями
**Priority:** High
**Status:** Done (2026-09-23)
**Effort:** 3 SP
**Refs:** E146

## User Story

> Как **пользователь** проводящий совещание,
> я хочу **вручную пометить только что сказанную фразу как "Решение"**,
> чтобы **сохранить её в списке решений с таймкодом** для протокола и экспорта.

## Acceptance Criteria

- [x] Каждая реплика имеет кнопку "+ ⚖️" для ручной пометки как решения (E146)
- [x] После пометки — badge ⚖️ и зелёная рамка вокруг реплики
- [x] Кнопка "🤖 Найти решения" — AI auto-extract (E147)
- [x] AI-пометки НЕ отменяют ручные (работают параллельно)
- [x] Дедупликация: повторный AI не дублирует существующие decision
- [x] На вкладке "Решения" — карточки с:
  - [x] Таймкод (timestamp_sec из start_sec utterance)
  - [x] Текст решения
  - [x] Удаление (×)
  - [x] Приоритет (badge)
  - [x] Кто принял решение (AI/пользователь)
  - [x] Когда создано
- [x] Клик на timestamp → перемотка аудио
- [x] Сортировка по timestamp
- [x] Backed через `POST /decisions` с `source_utterance_id`

## Technical Design

### Backend API (E146)

```python
# POST /decisions
{
  "protocol_id": "uuid",
  "text": "...",  // или из utterance
  "source_utterance_id": "uuid-u1",  // ← связано с репликой
  "priority": "medium",
  "source": "transcript" | "live"
}

# Возвращает DecisionResponse с timestamp_sec (из utterance.start_sec):
{
  "id": "uuid-decision",
  "text": "...",
  "priority": "medium",
  "timestamp_sec": 235.456,
  "source_utterance_id": "uuid-u1",
  "created_at": "2026-09-23T..."
}
```
