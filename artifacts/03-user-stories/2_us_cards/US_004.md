# US-004: Highlight неуверенных слов в транскрипции (low-confidence markers)

| Поле | Значение |
|---|---|
| **ID** | US-004 |
| **Эпик** | EPIC-TRANS |
| **Приоритет** | Should |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | ProtocolView → TranscriptTab |
| **API** | (внутри GET /api/v1/transcripts/{protocol_id}) |

## User Story
**Как** Алексей (P-01),
**я хочу** видеть визуальное выделение слов в транскрипции, которые Whisper распознал с низкой уверенностью (logprob < −1.0),
**чтобы** быстро находить сомнительные места и проверять их по аудио.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — шаг 2 (транскрипция) + шаг «Просмотр и правка».
- **Боль персоны:** «Whisper иногда слышит "прювет" вместо "привет" — хочу сразу видеть подозрительные слова, а не перечитывать весь протокол».
- **Связь с Vision:** §7.1 — подсветка «сомнительных слов»; вклад в KPI WER ≤15%.
- **Зависимость:** US-005 (транскрипция), US-008 (правка текста).

## Acceptance Criteria

- **AC-1:** Given транскрипция готова, When я открываю вкладку «Транскрипция», Then слова с `logprob < −1.0` подсвечены бледно-жёлтым фоном, с `logprob < −2.0` — оранжевым.

- **AC-2:** Given слово подсвечено как неуверенное, When я навожу на него мышь, Then появляется tooltip «Уверенность: 0.42 (низкая). Возможные альтернативы: привет, привал, приват».

- **AC-3:** Given в реплике много неуверенных слов (>30%), When я смотрю транскрипцию, Then слева от реплики появляется иконка ⚠ «Низкая уверенность» (деловая SVG, см. US-068).

- **AC-4:** Given я хочу отключить подсветку, When я нажимаю переключатель «Показывать неуверенные слова» в toolbar, Then подсветка убирается для всех слов (настройка сохраняется в localStorage).

- **AC-5:** Given я навожу на неуверенное слово, When я нажимаю на него, Then воспроизведение аудио прыгает на момент этого слова (таймкод из Whisper tokens), чтобы я мог перепроверить на слух.

- **AC-6:** Given Whisper не возвращает logprob (например, для Vosk), When идёт транскрипция, Then подсветка автоматически отключается, без ошибок.

## Технические заметки
- Whisper API: каждый token содержит `avg_logprob` (типично −0.2…−1.5) и `no_speech_prob`.
- Сохраняется в БД: `transcript_words (id, protocol_id, start_ms, end_ms, word, logprob, no_speech_prob)`.
- Цвета по Design System (US-068): warning `#d97706`, лёгкий warning фон `#fef3c7`.
- Альтернативные варианты (`alternatives`): Whisper возвращает top-N candidates — используются в tooltip.
