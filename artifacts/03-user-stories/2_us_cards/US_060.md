# US-060: Перемещение протокола в папку

| Поле | Значение |
|---|---|
| **ID** | US-060 |
| **Эпик** | EPIC-FOLDERS |
| **Приоритет** | Should |
| **Story Points** | 2 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | FolderSidebar, карточка протокола (drag-and-drop) |
| **API** | PUT /api/v1/hmp/protocols/{id}/folder |

## User Story
**Как** Алексей (P-01),
**я хочу** перетаскивать протоколы в нужную папку,
**чтобы** организовать свою встречи по проектам/командам без долгих кликов.

## Контекст
- **Процесс:** Организация протоколов.
- **Боль персоны:** «Открывать каждое меню для перемещения — долго».
- **Связь с Vision:** §7.1 Базовое ядро — «Локальная работа с данными».

## Acceptance Criteria

- **AC-1:** Given я в списке протоколов, When я наведу мышку на карточку, Then она показывает `cursor: grab` (можно тащить).

- **AC-2:** Given я начал тащить карточку, When я навожу её на папку в сайдбаре, Then папка подсвечивается зелёным (`border: dashed`).

- **AC-3:** Given я отпустил карточку над папкой, When drop срабатывает, Then Toast «Протокол перемещён» и список обновляется.

- **AC-4:** Given протокол в папке A, When я перетащу его в папку B, Then протокол исчезнет из папки A и появится в папке B.

- **AC-5:** Given я отпустил карточку над «Все протоколы» (без папки), When drop срабатывает, Then протокол выходит из папки (folder_id = null).

- **AC-6:** Given backend недоступен, When я пытаюсь переместить, Then Toast «Ошибка перемещения» и UI возвращается к предыдущему состоянию.

## Технические заметки
- Drag-and-drop API HTML5 (dragstart, dragover, drop)
- `dataTransfer.setData('text/plain', protocolId)`
- Backend атомарно обновляет folder_id
- Оптимистичные обновления в UI (можно откатить при ошибке)
