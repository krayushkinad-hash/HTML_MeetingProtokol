# US-048: Встраивание Яндекс Телемоста (embed-плеер)

## User Story
**Как** Алексей (P-01),
**я хочу** вставить ссылку на Яндекс Телемост в приложение, чтобы окно Телемоста открылось прямо внутри HTML_MeetingProtokol (iframe),
**чтобы** не переключаться между окнами во время встречи.

## Контекст
- **Процесс:** «Онлайн-встреча в Яндекс Телемост» — параллельный процесс.
- **Боль персоны:** «Окно браузера с Телемостом + окно с протоколом — alt+tab утомляет. Хочу всё в одном окне».
- **Связь с Vision:** §7.1 — «Я.Телемост встраивание»; §5 Преимущество #8 «Прямая интеграция с Яндекс Телемост».
- **KPI:** Переключение между панелями = 0 (всё в одном окне).

## Acceptance Criteria

- **AC-1:** Given я на странице «Live Mode», When я ввожу ссылку на Яндекс Телемост (`https://telemost.yandex.ru/j/XXXXX`) и нажимаю «Подключиться», Then iframe с Телемостом встраивается в левую панель, я вижу видео участников.

- **AC-2:** Given iframe загрузился, When я разрешаю доступ к микрофону/камере, Then я участвую во встрече прямо из приложения.

- **AC-3:** Given iframe загрузился, When я нажимаю «▶ Начать запись» (см. US-030), Then:
  - Захватывается аудио системного звука через `getDisplayMedia({audio: true})` (workaround для CORS)
  - ИЛИ через виртуальный аудио-драйвер (см. тех. заметки)
  - Запускается live-транскрипция (US-030)

- **AC-4:** Given iframe не может встроиться (CORS / X-Frame-Options), When я пытаюсь подключиться, Then я вижу сообщение «Телемост не позволяет встраивание. Откроется в новом окне» + кнопка «Открыть в новом окне».

- **AC-5:** Given встреча завершилась в Телемост, When я нажимаю «Отключиться», Then iframe очищается, аудио-захват останавливается, финальный протокол создаётся.

- **AC-6:** Given iframe встроен, When я хочу развернуть видео на весь экран, я нажимаю «⛶», видео Я.Телемост разворачивается (через Fullscreen API на iframe).

- **AC-7:** Given я в live mode, When у меня несколько встреч подряд, Then я могу переключаться между ними, история подключений сохраняется (последние 5 URL).

## Технические заметки
- **CORS-ограничение**: Яндекс Телемост имеет `X-Frame-Options: SAMEORIGIN` для большинства страниц, но iframe для join-ссылки может работать.
- **Workaround для аудио**: запись системного звука через `getDisplayMedia({audio: true})` (пользователь выбирает «весь экран» или «вкладку Телемост» с audio).
- **Альтернатива**: расширение для браузера, которое проксирует аудио (out of scope v1).
- **Electron-обёртка** (v2): `webview` tag с `nodeIntegration` для полного доступа к media stream — упростит захват аудио.
- **Privacy**: пользователь явно разрешает доступ к микрофону/камере/экрану.
