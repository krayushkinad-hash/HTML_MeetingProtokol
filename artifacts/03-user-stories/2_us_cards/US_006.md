## User Story
**Как** Алексей (P-01),
**я хочу**, чтобы после транскрипции Whisper автоматически расставил знаки препинания (точки, запятые, вопросительные знаки) и заглавные буквы,
**чтобы** читать текст протокола было удобно без сплошного потока «привет как дела я тоже норм а ты».

## Контекст
- **Процесс:** Этап «Подготовка протокола» — шаг 2.5 (между транскрипцией и диаризацией).
- **Боль персоны:** «Whisper выдаёт текст БЕЗ знаков препинания — читать невозможно, нужно править вручную».
- **Альтернатива:** можно использовать модели с пунктуацией (Silero, nemo), но LLM даёт более «человеческий» результат.
- **Связь с Vision:** §7.1 — «Восстановление пунктуации» (часть базового ядра).

## Acceptance Criteria

- **AC-1:** Given транскрипция Whisper завершена, When запускается этап пунктуации, Then LLM получает чанк текста (до 4096 токенов) и возвращает текст с расставленными `.`, `,`, `?`, `!`, заглавными буквами в начале предложений и после точек.

- **AC-2:** Given расстановка завершена, When я открываю протокол, Then я вижу текст с нормальной пунктуацией (≥95% предложений заканчиваются `.`, `?` или `!`).

- **AC-3:** Given LLM-сервис недоступен, When этап пунктуации падает, Then используется fallback — простая эвристика (Silero punct или nemo punct), без падения pipeline.

- **AC-4:** Given длинная запись (>2 ч), When обрабатывается текст, Then он подаётся в LLM чанками по 3000 символов с overlap 200 символов (чтобы не терять контекст на стыках).

- **AC-5:** Given я отключил LLM-фичи в настройках (приватный режим), When идёт транскрипция, Then этап пунктуации пропускается, текст остаётся как есть.

- **AC-6:** Given этап пунктуации выполнен, When я навожу на предложение, Then показывается tooltip «Пунктуация расставлена LLM. Может содержать ошибки».

## Технические заметки
- Промпт для LLM: «Восстанови пунктуацию в следующем тексте на русском языке. Сохрани все слова без изменений, только добавь знаки препинания и заглавные буквы: <TEXT>».
- Модели: primary — Hermes Agent (см. US-039), fallback — Silero punct (CPU, 50 МБ).
- Чанкинг: sliding window с overlap.
- Сохраняется `text_raw` (без пунктуации) + `text_punctuated` (с пунктуацией) — на случай отката.
