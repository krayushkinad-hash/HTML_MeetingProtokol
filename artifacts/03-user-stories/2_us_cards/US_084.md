# US-084 — Pause/Resume транскрибации + чистая ретранскрибация

**Epic:** US-005 — Транскрипция
**Priority:** High
**Status:** Done (2026-09-23)
**Effort:** 4 SP
**Refs:** E150, E151, E152, E153

## User Story

> Как **пользователь** записывающий длинные совещания,
> я хочу **поставить транскрибацию на паузу и продолжить позже (даже из другой вкладки)**,
> чтобы **не терять прогресс и иметь возможность прервать работу**.

> Как **контроль качества**, я хочу **безопасно запускать повторную транскрибацию**,
> чтобы **старые реплики не дублировались**.

## Technical Design

### Backend

```python
# POST /transcribe/pause/{task_id}
async def pause_transcription_endpoint(task_id, db):
    task = await db.get(TranscriptionTask, task_id)
    task.status = "paused"
    task.paused_at = datetime.now(timezone.utc)
    bg_task = _active_transcription_tasks.get(task_id)
    if bg_task:
        bg_task.cancel()
    return {"status": "paused", "can_resume": True, ...}

# POST /transcribe/resume/{task_id}
async def resume_transcription_endpoint(task_id, db):
    # E151: verify audio_hash
    audio_path = Path(audio_file.file_path)
    current_hash = hashlib.sha256(audio_path.read_bytes()).hexdigest()[:32]
    if task.audio_hash and task.audio_hash != current_hash:
        task.last_processed_sec = 0.0  # reset

    # Запускаем новый BG-task
    bg_task = asyncio.create_task(_resume_runner())
    register_active_task(task_id, bg_task)
```

### Re-transcription reset

```python
# В POST /transcribe/run — после INSERT db_task:
async with AsyncSessionLocal() as cleanup_db:
    await cleanup_db.execute(
        delete(Utterance).where(Utterance.protocol_id == body.protocol_id)
    )
    await cleanup_db.execute(
        delete(Decision).where(Decision.protocol_id == body.protocol_id)
    )
    await cleanup_db.commit()
```
