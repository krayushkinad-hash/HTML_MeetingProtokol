## User Story
**Как** Алексей (P-01),
**я хочу** экспортировать протокол в DOCX с таймкодами и репликами по ораторам,
**чтобы** отправить участникам встречи и/или приложить к проекту.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — финальный шаг «Экспорт результата».
- **Боль персоны:** «Хочу готовый документ, который можно сразу переслать — без ручной вёрстки».
- **Боль P-03:** «Хочу видеть итог протокола, чтобы проверить точность и попросить правки».
- **Связь с Vision:** §7.1 — «Экспорт DOCX со скриншотами»; §5 Ключевое преимущество #7 «DOCX-экспорт».

## Acceptance Criteria

- **AC-1:** Given протокол готов, When я нажимаю «Экспорт → DOCX», Then открывается диалог с настройками: «Включить таймкоды» (да/нет), «Включить скриншоты» (да/нет), «Включить гиперссылки на видео» (да/нет), «Группировать по ораторам» (да/нет).

- **AC-2:** Given я настроил параметры, When я нажимаю «Экспортировать», Then формируется DOCX-файл по стандарту (TNR 12, заголовки, таблицы «Сетка таблицы» — стиль Краюшкина).

- **AC-3:** Given DOCX сформирован, When я открываю файл, Then я вижу: титульный лист с названием и датой встречи, список участников, повестку, реплики с таймкодами, сгруппированные по ораторам.

- **AC-4:** Given в реплике есть таймкод, When я смотрю DOCX, Then рядом с таймкодом стоит гиперссылка «▶ 0:32» / «▶ 14:23», при клике открывается локальный видеофайл с этой секунды.

- **AC-5:** Given у меня есть скриншоты экрана (см. US-021), When я экспортирую с включёнными скриншотами, Then в DOCX встроены изображения с привязкой к моменту реплики.

## Технические заметки
- Формат DOCX — стандарт Краюшкина (TNR 12, поля 20/10/10/10, заголовки 1/2/3, таблицы «Сетка таблицы»).
- Файл формируется на backend (python-docx) или в браузере (docx.js) — выбор при реализации.
- Имя файла: `protocol_<YYYY-MM-DD>_<название>.docx` (кириллица допустима, но для отправки через Telegram лучше транслитерировать).
- Размер DOCX обычно 100–500 КБ (без скриншотов) или до 50 МБ (со скриншотами).
