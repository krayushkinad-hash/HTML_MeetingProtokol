# US-035: Шаринг протокола через публичную ссылку

| Поле | Значение |
|---|---|
| **ID** | US-035 |
| **Эпик** | EPIC-SHARE |
| **Приоритет** | Could |
| **Story Points** | 8 |
| **Персона** | P-01 Алексей (Windows), P-03 Гость |
| **Форма** | ProtocolView → ShareDialog |
| **API** | POST /api/v1/share/{protocol_id}, GET /share/{token} |

## User Story
**Как** Алексей (P-01),
**я хочу** сгенерировать публичную ссылку на протокол (read-only) и отправить её участникам встречи по email/Telegram,
**чтобы** они могли посмотреть протокол без установки приложения и без логина.

## Контекст
- **Процесс:** «Поделиться результатом» — поперечный процесс.
- **Боль персоны:** «Отправляю DOCX участникам — но у них может быть старый Word, или они на Mac, или в дороге без ноутбука. Хочу просто ссылку».
- **Боль P-03:** «Получаю ссылку, открываю в браузере, читаю — без логина и без установки».
- **Связь с Vision:** §7.1 — «Шаринг протокола»; §5 Преимущество #3 «Хронологическая база».

## Acceptance Criteria

- **AC-1:** Given я на странице протокола, When я нажимаю «🔗 Поделиться», Then открывается диалог с настройками:
  - Чекбокс «Только саммари+задачи+решения» (без транскрипции)
  - Чекбокс «Включить видео» (доступ к локальному видео)
  - Поле «Срок действия ссылки» (1 день / 7 дней / 30 дней / Бессрочно)
  - Чекбокс «Защитить паролем» (опционально)
  - Кнопка «Создать ссылку»

- **AC-2:** Given я создал ссылку, When диалог показывает результат, Then я вижу:
  - URL вида `https://localhost:8000/share/<token>`
  - Кнопка «📋 Копировать»
  - QR-код для мобильных

- **AC-3:** Given я (как гость) перешёл по ссылке, When страница загружается, Then я вижу протокол в read-only режиме (без кнопок редактирования), с водяным знаком «Shared by Алексей».

- **AC-4:** Given ссылка защищена паролем, When я перешёл по ссылке, Then сначала показывается форма «Введите пароль», после ввода — протокол.

- **AC-5:** Given срок ссылки истёк, When я перехожу по ссылке, Then я вижу «Срок действия ссылки истёк. Попросите автора создать новую».

- **AC-6:** Given ссылка была отозвана, When я перехожу, Then я вижу «Ссылка отозвана автором».

- **AC-7:** Given я в Astra Linux офлайн (P-02), When я пытаюсь создать ссылку, Then я вижу «Шаринг требует сетевого доступа. Создайте DOCX-экспорт (US-024) для офлайн-передачи».

## Технические заметки
- Backend: `shares (id, protocol_id, token, expires_at, password_hash, is_revoked, created_at)`.
- Token: UUID4 или nanoid (16 символов).
- Пароль: bcrypt hash.
- Маршрут: `/share/<token>` — публичный endpoint, не требует аутентификации.
- Данные: только текст + метаданные (НЕ видео, если не включено). Видео отдаётся через signed URL с коротким TTL.
- Лимит: до 10 активных ссылок на протокол.

## Связанные артефакты
- Vision: §7.1 Шаринг протокола
- Persona: P-01 (создаёт), P-03 (получает)
