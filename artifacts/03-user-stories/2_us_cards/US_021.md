# US-021: Аутентификация (логин/пароль, локальный пользователь)

| Поле | Значение |
|---|---|
| **ID** | US-021 |
| **Эпик** | EPIC-AUTH |
| **Приоритет** | Must |
| **Story Points** | 5 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | LoginForm, SettingsPage → AccountTab |
| **API** | POST /api/v1/auth/login, POST /api/v1/auth/logout |

## User Story
**Как** Алексей (P-01),
**я хочу** при первом запуске задать логин и пароль, а при последующих — вводить пароль для входа,
**чтобы** защитить локальные данные от случайного доступа (членов семьи, коллег за компьютером).

## Контекст
- **Процесс:** «Запуск приложения» — шаг 0 (аутентификация).
- **Боль персоны:** «Данные конфиденциальные — записи совещаний с заказчиками. Если кто-то откроет мой компьютер — увидит всё».
- **Связь с Vision:** §7.1 — «Базовая безопасность», §8 Risk #3 «Несанкционированный доступ».
- **Допущение:** Это **локальное** desktop-приложение, не SaaS. Один пользователь. Нет мультитенантности.

## Acceptance Criteria

- **AC-1:** Given я запускаю приложение впервые, When открывается страница приветствия, Then я вижу форму «Создать локального пользователя»: поля «Логин», «Пароль», «Подтверждение пароля», кнопка «Создать».

- **AC-2:** Given я создал пользователя, When я ввёл пароль ≥8 символов (буквы + цифры) и подтвердил, Then пароль хешируется (bcrypt/argon2), сохраняется в БД, я автоматически вхожу в систему, вижу главную страницу.

- **AC-3:** Given я перезапустил приложение, When открывается экран входа, Then я вижу форму «Вход»: поля «Логин», «Пароль», кнопка «Войти». После ввода корректных данных — вход, иначе — «Неверный логин или пароль».

- **AC-4:** Given я забыл пароль, When я нажимаю «Забыли пароль?», Then я вижу предупреждение «Локальное приложение, восстановление невозможно. Сброс = удаление всех данных. Продолжить?» — с подтверждением.

- **AC-5:** Given я вошёл, When я нахожусь в системе 30 минут без активности, Then сессия автоматически завершается, требуется повторный ввод пароля (настраиваемый таймаут, по умолчанию 30 мин).

- **AC-6:** Given я хочу сменить пароль, When я открываю Настройки → Аккаунт, Then я могу ввести старый пароль и дважды новый, после подтверждения пароль обновляется.

- **AC-7:** Given 5 неудачных попыток входа подряд, When я пытаюсь войти снова, Then аккаунт блокируется на 5 минут (защита от brute force), в логе появляется событие безопасности.

## Технические заметки
- Хеширование: bcrypt (cost=12) или argon2id (memory=64MB, time=3).
- Сессии: JWT или cookie-based session (HttpOnly, Secure).
- Пароль НИКОГДА не сохраняется в открытом виде и НЕ логируется.
- Для desktop-приложения можно опционально использовать системный keyring (Windows Credential Manager / macOS Keychain / Linux Secret Service).
- Зависимость: US-042 (audit log для событий входа/выхода/смены пароля).
