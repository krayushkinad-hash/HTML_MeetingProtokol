# US-075: Скачивание Whisper моделей с прогресс-баром (US-058)

| Поле | Значение |
|---|---|
| **ID** | US-075 |
| **Эпик** | EPIC-SETTINGS |
| **Приоритет** | Must |
| **Story Points** | 5 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | WhisperModelsView + SettingsPage → TranscriptionTab (inline) |
| **API** | GET /whisper/models, POST /whisper/download/{name}, GET /whisper/progress/{name} |

## User Story
**Как** Алексей (P-01),
**я хочу** видеть список всех доступных моделей Whisper, скачивать их с прогрессом (MB/сек), активировать нужную,
**чтобы** управлять памятью и временем транскрипции.

## Контекст
- **Процесс:** Первоначальная настройка + перед большой встречей (large-v3).
- **Боль персоны:** «Не знаю какие модели уже скачаны, сколько места занимают».
- **Связь с Vision:** §7.1 «Локальная транскрипция через Whisper». §10.5 «Управление локальной моделью».

## Acceptance Criteria

- **AC-1:** Given я открыл «Настройки → Транскрипция» или `#/whisper`, When загружается страница, Then вижу список из 9 моделей: tiny (75 MB), base (140 MB), small (460 MB), medium (1.5 GB), large-v2 (3 GB), large-v3 (3 GB), distil-small-en (310 MB), distil-medium-en (780 MB), distil-large-v3 (1.5 GB).

- **AC-2:** Given я нажимаю «📥 Скачать» на неcкачанной модели, Then появляется прогресс-бар с процентом, MB/sec скоростью и ETA.

- **AC-3:** Given скачивание завершено (>99%), When polling, Then UI обновляется: статус становится «CACHED», кнопка «Скачать» исчезает, появляется «Сделать активной» и «Удалить».

- **AC-4:** Given я нажимаю «✅ Сделать активной», Then backend сохраняет выбор, в логе появляется `whisper_active_model_changed`, при следующей транскрипции используется новая модель.

- **AC-5:** Given я удаляю скачанную модель, Then файл удаляется с диска, карточка становится «NOT CACHED».

## Технические заметки

### Модели (стандартные faster-whisper):
| name | size_mb | language | hf repo |
|---|---|---|---|
| tiny | 75 | multi | Systran/faster-whisper-tiny |
| base | 140 | multi | Systran/faster-whisper-base |
| small | 460 | multi | Systran/faster-whisper-small |
| medium | 1500 | multi | Systran/faster-whisper-medium |
| large-v2 | 3000 | multi | Systran/faster-whisper-large-v2 |
| large-v3 | 3100 | multi | Systran/faster-whisper-large-v3 |
| distil-small-en | 310 | en only | Systran/faster-distil-whisper-small.en |
| distil-medium-en | 780 | en only | Systran/faster-distil-whisper-medium.en |
| distil-large-v3 | 1500 | en only | Systran/faster-distil-whisper-large-v3 |

### Cache directory (по умолчанию):
- Windows: `%LOCALAPPDATA%\.cache\huggingface\hub`
- Linux/Mac: `~/.cache/huggingface/hub`

### Backend endpoints:
```
GET  /whisper/models           — список с download status
GET  /whisper/models/{name}    — детали (path, size_mb_on_disk)
GET  /whisper/active           — какая активна сейчас
POST /whisper/active/{name}    — сменить активную
POST /whisper/download/{name}  — скачать (background asyncio task, 202)
GET  /whisper/progress/{name}  — прогресс (percent, speed_mbps)
GET  /whisper/status/{name}    — скачана ли?
DELETE /whisper/models/{name}  — удалить с диска
```

### Frontend (UI):
- `#/whisper` — страница-менеджер с сеткой 9 карточек
- Settings → Transcription — inline status виджет + кнопка «Скачать» если модель не скачана
- Polling каждые 1-1.5 сек
