## User Story
**Как** Алексей (P-01),
**я хочу** добавить к протоколу теги вручную (например, «заказчик-Х», «Q4-2026», «важно», «для-команды»),
**чтобы** группировать протоколы по проектам, периодам и темам для быстрой фильтрации.

## Контекст
- **Процесс:** «Организация базы протоколов» — поперечный процесс.
- **Боль персоны:** «У меня 200 протоколов — без тегов найти "все встречи по заказчику Х" невозможно».
- **Связь с Vision:** §7.1 — «Теги протокола»; §6 Цель #6 «AI-фичи: тегирование».
- **Связь с US-029:** Ручные теги (эта US) vs автогенерация (US-029).

## Acceptance Criteria

- **AC-1:** Given я на странице протокола, When я нажимаю на иконку тегов или открываю вкладку «Теги», Then я вижу поле ввода «Добавить тег» + список уже существующих тегов с цветными плашками.

- **AC-2:** Given я ввёл «заказчик-Х» и нажал Enter, When тег сохраняется, Then он появляется в списке тегов протокола, в списке протоколов на карточке также отображается.

- **AC-3:** Given я хочу удалить тег, When я нажимаю «×» рядом с тегом, Then тег удаляется из протокола (с подтверждением «Удалить тег 'заказчик-Х'?»).

- **AC-4:** Given я начал вводить «зад...», When появляется autocomplete, Then система предлагает существующие теги («заказчик-Х», «задачи», «запуск»), я могу выбрать из списка (Tab/Enter) или ввести новый.

- **AC-5:** Given у меня 50 протоколов с тегом «Q4-2026», When я на главной странице нажимаю на тег «Q4-2026», Then фильтруется список: видны только протоколы с этим тегом.

- **AC-6:** Given я хочу переименовать тег (исправить опечатку, глобально), When я захожу в Настройки → Управление тегами и нажимаю «Переименовать», Then все протоколы с этим тегом обновляются.

- **AC-7:** Given я задал теги, When я экспортирую DOCX, Then теги отображаются на титульном листе строкой «Теги: заказчик-Х, Q4-2026, важно».

## Технические заметки
- Хранение: `tags (id, name, color_hex, user_id, created_at)` + `protocol_tags (protocol_id, tag_id)` (many-to-many).
- Цвет тега: автогенерация по hash имени (HSL) или выбор из палитры (опционально).
- Autocomplete: SQL `SELECT name FROM tags WHERE name LIKE 'зад%' LIMIT 10`.
- Валидация: длина тега 2–30 символов, допустимы кириллица, латиница, цифры, дефис.
- Лимит: ≤20 тегов на протокол (иначе UI нечитабельный).
