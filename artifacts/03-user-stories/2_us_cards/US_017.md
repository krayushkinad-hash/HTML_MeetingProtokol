# US-017: Гиперссылки «▶ HH:MM:SS» в DOCX на локальное видео

| Поле | Значение |

| **Эпик** | EPIC-DOCX |
| **Приоритет** | Should |

| **Форма** | ExportDialog |

## User Story
**Как** Алексей (P-01),
**я хочу**, чтобы в DOCX рядом с каждой репликой стояла гиперссылка «▶ HH:MM:SS» на локальный видеофайл,
**чтобы** участник мог кликнуть и сразу перейти к нужному моменту разговора.

## Контекст
- **Процесс:** «Экспорт DOCX» — этап «Подготовка протокола».
- **Боль персоны:** «Хочу, чтобы участник мог не читать текст, а сразу услышать, как это обсуждалось. Клик → видео с момента».
- **Связь с Vision:** §7.1 «DOCX-экспорт: возможность «показать видео с временной отметки» прямо из DOCX (гиперссылка на локальный файл)».

## Acceptance Criteria

- **AC-1:** Given у реплики есть таймкод (например, 14:23), When DOCX сформирован, Then рядом с репликой стоит кликабельный текст «▶ 14:23» (синий, подчёркнутый).

- **AC-2:** Given я кликнул по гиперссылке в Word/LibreOffice, When открывается ссылка, Then запускается системный видеоплеер по умолчанию (VLC, Movies & TV, ...) и воспроизведение начинается с указанной секунды.

- **AC-3:** Given видеофайл лежит локально (`~/.html_mp/protocols/<id>/video.mp4`), When гиперссылка формируется, Then она указывает на относительный или абсолютный путь к файлу + параметр `#t=14:23` (или URL с фрагментом времени).

- **AC-4:** Given видеофайл был перемещён или удалён, When я кликаю по гиперссылке, Then я вижу понятное сообщение «Файл видео не найден. Проверьте, что вы получили полный комплект файлов (видео + протокол)».

- **AC-5:** Given DOCX отправляется участнику по email, When участник открывает файл, Then гиперссылки могут не работать (если у участника нет видео файла) — это явно указано в инструкции «Для работы гиперссылок приложите видеофайл к письму или загрузите в общее хранилище».

## Технические заметки

### Формат гиперссылки

Вариант A (относительный путь):
```
file:./video.mp4#t=14:23
```

Вариант B (абсолютный путь — переносимый, но менее универсальный):
```
file:///C:/Users/alex/.html_mp/protocols/abc/video.mp4#t=14:23
```

Вариант C (URL с протоколом):
```
html-mp://local/<protocol_id>?t=14:23
```
(требует регистрации протокола в системе — сложно)

**Рекомендация:** использовать вариант A с относительным путём и явно указать в сопроводительном письме: «Положите этот DOCX рядом с видеофайлом video.mp4».

### Техническая реализация

В `python-docx` нет встроенного метода для гиперссылок, нужна обёртка:

```python
from docx.oxml.ns import qn
from docx.oxml import OxmlElement

def add_hyperlink(paragraph, url, text):
    part = paragraph.part
    r_id = part.relate_to(url, 'http://schemas.openxmlformats.org/officeDocument/2006/relationships/hyperlink', is_external=True)
    hyperlink = OxmlElement('w:hyperlink')
    hyperlink.set(qn('r:id'), r_id)
    new_run = OxmlElement('w:r')
    rPr = OxmlElement('w:rPr')
    color = OxmlElement('w:color'); color.set(qn('w:val'), '0000FF')
    u = OxmlElement('w:u'); u.set(qn('w:val'), 'single')
    rPr.append(color); rPr.append(u)
    new_run.append(rPr)
    t = OxmlElement('w:t'); t.text = text
    new_run.append(t)
    hyperlink.append(new_run)
    paragraph._p.append(hyperlink)
    return hyperlink
```

### Безопасность
- `file://` ссылки в DOCX — Office спрашивает «Открыть ссылку?». Это нормально.
- НЕ использовать `javascript:` или другие опасные протоколы.
- При сборке валидировать, что URL начинается с `file:` или `http(s):`.
