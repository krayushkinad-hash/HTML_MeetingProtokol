# US-036: Локализация (i18n) — русский + английский

| Поле | Значение |
|---|---|
| **ID** | US-036 |
| **Эпик** | EPIC-I18N |
| **Приоритет** | Should |
| **Story Points** | 5 |
| **Персона** | P-01 Алексей (Windows), потенциально иностранные коллеги |
| **Форма** | SettingsPage → GeneralTab (language selector) |
| **API** | PATCH /api/v1/user-setting (language) |

## User Story
**Как** Алексей (P-01),
**я хочу** переключить язык интерфейса между русским и английским,
**чтобы** делиться приложением с иностранными коллегами или использовать его в англоязычной среде.

## Контекст
- **Процесс:** Использование приложения (глобальная настройка).
- **Боль персоны:** «Если приглашу в проект англоязычного консультанта — он не поймёт русский интерфейс. Хочу переключение».
- **Связь с Vision:** §7.1 — i18n; §5 Преимущество #8 «Международный потенциал».
- **Допущение:** v1 поддерживает ru + en, остальные языки — out of scope.

## Acceptance Criteria

- **AC-1:** Given я открываю Настройки → Общие, When страница загружена, Then я вижу выпадающий список «Язык интерфейса» с опциями: «Русский» / «English».

- **AC-2:** Given я выбрал «English», When я нажимаю «Сохранить», Then интерфейс мгновенно переключается на английский (без перезагрузки): «Протоколы» → «Protocols», «Загрузить» → «Upload», «Настройки» → «Settings».

- **AC-3:** Given я переключил язык, When я перезагружаю страницу, Then выбранный язык сохраняется (в localStorage + в БД через user-setting).

- **AC-4:** Given приложение запускается впервые, When нет сохранённого языка, Then язык определяется по `navigator.language`: если начинается с «ru» → русский, иначе → английский.

- **AC-5:** Given я переключил язык, When формируется DOCX (US-024), Then:
  - Заголовки секций («Саммари», «Задачи», «Решения») — на выбранном языке
  - Шаблон Краюшкина остаётся на русском (это ГОСТ) — опционально через настройку шаблона

- **AC-6:** Given я переключил язык, When идёт транскрипция, Then Whisper по-прежнему использует русский язык (если источник русский) — язык UI не влияет на язык распознавания.

- **AC-7:** Given я переключил язык, When я смотрю на LLM-промпты, Then они тоже локализуются: промпт для саммари на русском → выдаёт саммари на русском, промпт на английском → саммари на английском.

## Технические заметки
- Библиотека: `i18next` + `i18next-browser-languagedetector`.
- Структура: `locales/ru/translation.json`, `locales/en/translation.json`.
- Формат ключей: точечная нотация (`protocols.tab.summary`, `settings.notifications.title`).
- Pluralization: встроенная поддержка в i18next (`key_one`, `key_few`, `key_many` для русского).
- Даты/числа: `Intl.DateTimeFormat`, `Intl.NumberFormat` — авто-формат по языку.
- Coverage: ≥90% строк локализованы (остальные — fallback на английский).
