## User Story
**Как** Алексей (P-01),
**я хочу** настроить GigaChat как fallback LLM-провайдер,
**чтобы** если основной (Hermes Agent) недоступен, саммари и извлечение задач всё равно работали.

## Контекст
- **Процесс:** Настройка AI-фичей.
- **Боль персоны:** «Hermes Agent — мой primary, но он может быть недоступен. GigaChat — российский, есть бесплатный тариф, подойдёт как fallback».
- **Связь с Vision:** §7.5 — «LLM-провайдеры: primary + fallback»; §6 Цель #6.
- **Связь с US-039:** Hermes Agent — primary, GigaChat — fallback #1, Ollama — offline fallback (US-040).

## Acceptance Criteria

- **AC-1:** Given я открываю Настройки → AI провайдер, When страница загружена, Then я вижу карточку GigaChat с полями:
  - «API Key» (от developers.sber.ru)
  - «Scope» (по умолчанию `GIGACHAT_API_PERS`)
  - «Model» (GigaChat / GigaChat-Plus / GigaChat-Pro)
  - Чекбокс «Включить как fallback»
  - Кнопка «Проверить подключение»

- **AC-2:** Given я ввёл API Key и нажал «Проверить», When backend делает тестовый запрос к GigaChat API, Then я вижу зелёную плашку «Подключение успешно. Модель: GigaChat-Plus» (или ошибку с описанием).

- **AC-3:** Given GigaChat включён как fallback, When Hermes Agent возвращает ошибку (timeout / 5xx / quota exceeded), Then система автоматически переключается на GigaChat для следующего запроса.

- **AC-4:** Given переключение на GigaChat, When идёт саммари, Then я вижу в UI индикатор «🤖 Провайдер: GigaChat (fallback)» в footer-е progress-bar (US-020).

- **AC-5:** Given Hermes Agent снова доступен, When следующий запрос, Then система возвращается к primary (без ручного переключения).

- **AC-6:** Given я отключил GigaChat в настройках, When fallback не настроен, Then при недоступности Hermes я вижу ошибку «Все LLM-провайдеры недоступны. Проверьте настройки AI».

- **AC-7:** Given я использую GigaChat, When идёт транскрипция (транскрипция — НЕ LLM-операция), Then GigaChat НЕ используется (только Whisper), fallback работает только для AI-фичей (саммари, задачи, решения, автотеги).

## Технические заметки
- Endpoint GigaChat: `https://gigachat.devices.sberbank.ru/api/v1/chat/completions`.
- Авторизация: OAuth2 token endpoint `https://ngw.devices.sberbank.ru:9443/api/v2/oauth`.
- Token cache: хранится в памяти до истечения (обычно 30 мин), refresh при 401.
- Retry policy: 2 попытки с exponential backoff (1 сек, 2 сек).
- Библиотека: `gigachat` (официальный Python SDK) или httpx.
- Стоимость: GigaChat Lite — бесплатно, Plus/Pro — платные тарифы.
