# US-061: Удаление и переименование папки

| Поле | Значение |

| **API** | DELETE/PATCH /api/v1/hmp/folders/{id} |

## User Story
**Как** Алексей (P-01),
**я хочу** удалять ненужные папки и переименовывать существующие,
**чтобы** поддерживать чистоту в организационной структуре.

## Контекст
- **Процесс:** Управление папками.
- **Боль персоны:** «Не могу исправить опечатку в названии папки».
- **Связь с Vision:** §7.1 Базовое ядро — «Локальная работа с данными».

## Acceptance Criteria

- **AC-1:** Given я навожу мышку на папку, When я нажимаю «✕» рядом с папкой, Then появляется confirm «Удалить папку "Имя"? Протоколы из неё останутся доступными, но без категории».

- **AC-2:** Given я подтвердил удаление, When выполняется запрос, Then папка удаляется из БД, протоколы получают folder_id = null (не удаляются), Toast «Папка удалена».

- **AC-3:** Given я дважды кликаю по названию папки, When поле становится редактируемым, Then я могу изменить имя и нажать Enter для сохранения.

- **AC-4:** Given я переименовал папку, When сохраняю (Enter или blur), Then PATCH запрос к API, обновлённое имя в сайдбаре.

- **AC-5:** Given backend упал при удалении, When запрос не удался, Then Toast «Ошибка удаления» и папка остаётся.

## Технические заметки
- Удаление: `DELETE /folders/{id}` — каскадно через `ON DELETE SET NULL` в БД
- Переименование: `PATCH /folders/{id}` с полем `name`
- Вложенные папки: `parent_id` ссылка (при удалении parent — children остаются с ON DELETE CASCADE)
- Drag-and-drop не используется для переименования
