# US-047: Ручной capture скриншотов из видео

| Поле | Значение |
|---|---|
| **ID** | US-047 |
| **Эпик** | EPIC-SCREENS |
| **Приоритет** | Should |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | ProtocolView → VideoPlayer → Capture button |
| **API** | POST /api/v1/protocols/{id}/screenshots |

## User Story
**Как** Алексей (P-01),
**я хочу** во время просмотра видео протокола нажать кнопку «📸 Скриншот» в нужном моменте,
**чтобы** сохранить кадр как скриншот с привязкой к текущему таймкоду — вручную, без автоматического захвата.

## Контекст
- **Процесс:** «Просмотр и редактирование протокола».
- **Боль персоны:** «Не во всех встречах нужен авто-capture (US-046). Иногда хочу выборочно сохранить 3–5 ключевых моментов из 2-часового видео».
- **Связь с Vision:** §7.1 — «Ручной capture скриншотов»; §5 Преимущество #6.
- **Альтернатива US-046:** US-046 автоматический, US-047 ручной.

## Acceptance Criteria

- **AC-1:** Given я на странице протокола с видеоплеером, When я навожу на плеер, Then появляется кнопка «📸 Скриншот» (overlay, в правом верхнем углу).

- **AC-2:** Given плеер показывает момент 14:23, When я нажимаю «📸 Скриншот», Then:
  - Backend извлекает кадр из видео на 14:23 (через ffmpeg)
  - Сохраняет в `~/.html_mp/protocols/<id>/screenshots/<HH-MM-SS>.png`
  - Регистрирует в `screenshots` таблице с timestamp = 14:23
  - Скриншот появляется в панели «Скриншоты» в протоколе

- **AC-3:** Given я сделал скриншот, When я смотрю список скриншотов, Then я могу добавить подпись к скриншоту (текстовое описание: «Схема архитектуры», «График retention»).

- **AC-4:** Given я хочу удалить ненужный скриншот, When я нажимаю «🗑» рядом с ним, Then файл удаляется с диска, запись удаляется из БД (с подтверждением).

- **AC-5:** Given у меня уже есть авто-скриншоты (US-046), When я делаю ручной, Then он добавляется к существующим, не заменяет их.

- **AC-6:** Given клавиша «S» (или Space + S), When я нажимаю в режиме просмотра видео, Then срабатывает shortcut для capture (без клика мышью).

- **AC-7:** Given видео не загружено, When я пытаюсь сделать capture, Then кнопка «📸» неактивна (disabled), с tooltip «Сначала загрузите видео».

## Технические заметки
- Backend: ffmpeg команда `ffmpeg -ss HH:MM:SS -i video.mp4 -frames:v 1 -q:v 2 screenshot.png`.
- Frame extraction latency: ≤2 сек для 2-часового видео.
- Сохраняется в формате PNG (исходное качество).
- Подписи: `screenshots.caption TEXT NULL`.
- Shortcut регистрируется через `keydown` listener (если фокус на плеере).
