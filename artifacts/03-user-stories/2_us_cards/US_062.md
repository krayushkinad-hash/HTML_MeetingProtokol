# US-062: Drag-and-drop интерфейс для папок

| Поле | Значение |
|---|---|
| **ID** | US-062 |
| **Эпик** | EPIC-FOLDERS |
| **Приоритет** | Should |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | FolderSidebar + список протоколов |
| **API** | PUT /api/v1/hmp/protocols/{id}/folder |

## User Story
**Как** Алексей (P-01),
**я хочу** перетаскивать протоколы между папками прямо в списке с визуальной обратной связью,
**чтобы** интуитивно понимать куда я перемещаю и видеть результат сразу.

## Контекст
- **Процесс:** Организация протоколов.
- **Боль персоны:** «Текущий drag-and-drop без визуального feedback — не понятно сработало или нет».
- **Связь с Vision:** §7.5 UI/UX — современный, отзывчивый интерфейс.

## Acceptance Criteria

- **AC-1:** Given протокол в папке A, When я тащу его в папку B, Then визуально подсвечивается зона drop (зелёный dashed border).

- **AC-2:** Given протокол тащится, When я выхожу за пределы папки, Then подсветка исчезает (drag-over класс снимается).

- **AC-3:** Given drop выполнен успешно, When API возвращает 200, Then Toast «Протокол перемещён», карточка с анимацией уходит из старого места.

- **AC-4:** Given drop выполнен с ошибкой, When API возвращает 5xx, Then Toast «Ошибка перемещения», карточка возвращается на старое место.

- **AC-5:** Given я тащу протокол очень быстро, When drop срабатывает, Then система корректно обрабатывает (нет race condition).

- **AC-6:** Given filter активен (папка A), When я перетаскиваю ВИЗИТЬ из папки A в папку B, Then фильтр сбрасывается на "Все протоколы" и я вижу, где теперь протокол.

## Технические заметки
- События HTML5: dragstart, dragover, dragleave, drop
- `dataTransfer.setData('text/plain', protocolId)`
- Класс `.drag-over` для визуального feedback
- CSS transitions для плавности анимаций
- Edge case: dragover должен `preventDefault()` чтобы drop работал
