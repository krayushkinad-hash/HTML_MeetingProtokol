# US-018: Drag-and-drop загрузка файла

| Поле | Значение |
|---|---|
| **ID** | US-018 |
| **Эпик** | EPIC-FILE |
| **Приоритет** | Must |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | UploadForm (drag-drop overlay) |
| **API** | POST /api/v1/transcribe/upload (тот же, что US-001) |

## User Story
**Как** Алексей (P-01),
**я хочу** перетащить аудио/видеофайл из проводника прямо в окно браузера,
**чтобы** не открывать диалог выбора файла — одним drag из папки в приложение.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — шаг 1 (загрузка файла).
- **Боль персоны:** «Файл уже в проводнике, открыл диалог, ищу файл, кликаю… хочу drag-and-drop прямо в окно».
- **Связь с Vision:** §7.1 — UX загрузки; снижение трения на шаге 1.
- **Связь с US-001:** Альтернативный input для того же endpoint.

## Acceptance Criteria

- **AC-1:** Given я открыл приложение, When я перетаскиваю файл из Проводника Windows в окно браузера, Then появляется overlay «Отпустите файл для загрузки» (полупрозрачный синий фон, иконка upload).

- **AC-2:** Given overlay показан, When я отпускаю файл над окном, Then файл загружается через тот же endpoint, что и US-001, появляется протокол со статусом «Загружен».

- **AC-3:** Given я тащу несколько файлов одновременно, When я отпускаю их, Then загружаются все (batch), создаётся несколько протоколов.

- **AC-4:** Given формат файла не поддерживается (.txt, .docx), When я отпускаю файл, Then я вижу сообщение «Формат .txt не поддерживается. Допустимо: mp3, wav, mp4, mkv».

- **AC-5:** Given файл >2 ГБ, When я отпускаю файл, Then появляется предупреждение «Большой файл. Продолжить?» (аналогично US-001 AC-3).

- **AC-6:** Given я случайно начал drag текста из Word, When я тащу над окном, Then overlay не показывается (drag только для файлов), drag игнорируется.

- **AC-7:** Given идёт загрузка drag-and-drop, When я перетаскиваю второй файл, Then он добавляется в очередь загрузки (не заменяет текущий).

## Технические заметки
- Frontend: `dragenter`, `dragover`, `dragleave`, `drop` events на `document.body`.
- `e.dataTransfer.files` — FileList с перетащенными файлами.
- Проверка типа файла по расширению и MIME (двойная валидация — на frontend и backend).
- Предотвращение default behavior браузера (открытие файла вместо drop).
