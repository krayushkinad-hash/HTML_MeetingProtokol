# US-070: Сохранение и отображение реального имени файла

| Поле | Значение |
|---|---|
| **ID** | US-070 |
| **Эпик** | EPIC-FILE |
| **Приоритет** | Must |
| **Story Points** | 2 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | ProtocolView → file-info, AudioFile metadata |
| **API** | GET /api/v1/hmp/audio-files/{id}, GET /api/v1/hmp/media/protocols/{id}/source.{ext} |

## User Story
**Как** Алексей (P-01),
**я хочу** чтобы имя файла на диске совпадало с тем что я вижу в UI,
**чтобы** не путаться и легко находить файлы в проводнике.

## Контекст
- **Процесс:** Загрузка + просмотр протокола.
- **Боль персоны:** «Загрузил SWB.mp4, на диске source.mp4. Ищу в проводнике SWB.mp4, не нахожу».
- **Связь с Vision:** §7.5 «Локальная работа с файлами».

## Acceptance Criteria

- **AC-1:** Given я загружаю файл `Мнтц 2.2.26.m4a`, When файлы сохраняются, Then на диске есть файл с тем же именем.

- **AC-2:** Given я открываю протокол в UI, When отображается file-info, Then имя файла в UI = имя файла на диске.

- **AC-3:** Given файлы уже загружены (старая версия), When backend стартует, Then существующие записи в БД обновляются — file_path использует реальное имя файла (если возможно).

- **AC-4:** Given я загружаю файл, Then `_as_uniqified()` генерирует уникальное имя добавляя timestamp или UUID суффикс если файл с таким именем уже есть.

- **AC-5:** Given я удаляю протокол, Then папка протокола удаляется вместе с файлом.

## Технические заметки

### Проблема (было):

```python
# protocols.py - создание протокола
audio_path = protocols_path / f"source.{extension}"  # Всегда "source.mp4"
audio_path.write_bytes(file_bytes)

audio_file = AudioFile(
    file_path=str(audio_path),  # → "source.mp4"
    filename=file.filename or f"unknown.{extension}",  # → "Мнтц 2.2.26.m4a"
    ...
)
```

**Проблема:** filename != file_path — рассинхрон.

### Решение:

**Подход 1:** Использовать `file.filename` для file_path
```python
# Сохранить как "Мнтц 2.2.26.m4a"
audio_path = protocols_dir / file.filename
# Если файл существует — добавить timestamp
if audio_path.exists():
    stem = audio_path.stem
    suffix = audio_path.suffix
    timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
    audio_path = protocols_dir / f"{stem}_{timestamp}{suffix}"
```

**Подход 2 (выбран):** Хранить файл как `source.{ext}`, но хранить оригинальное имя в БД для отображения

**Подход 3 (комбинированный):** 
- Сохранить с оригинальным именем
- Сохранить в файл `original_filename` для отображения в UI
- На диске будет реальное имя файла

**Выбран подход 3** — минимальные изменения в существующей логике.

### Изменения:

1. `protocols.py` — сохранять с оригинальным именем
2. Удалить старые файлы `source.{ext}` если есть
3. Не нужен дополнительный шаг миграции (старые протоколы имеют реальные файлы)
