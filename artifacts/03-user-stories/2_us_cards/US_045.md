## User Story
**Как** Алексей (P-01),
**я хочу** задать словарь замен: «Whisper пишет X → должно быть Y» (например, «Postgre SQL» → «PostgreSQL», «т елеграм» → «Telegram»),
**чтобы** при транскрипции и AI-корректировке термины автоматически исправлялись.

## Контекст
- **Процесс:** Настройка приложения (по мере необходимости).
- **Боль персоны:** «Whisper упорно пишет "Postgre SQL" через пробел, или "Яндекс диск" — а у нас в проекте "Яндекс.Диск" и "PostgreSQL". Приходится каждый раз править».
- **Связь с Vision:** §7.1 — «Пользовательский словарь»; §6 Цель #6 «AI-фичи».
- **Зависимость:** US-005 (транскрипция), US-006 (пунктуация), US-044 (cleanup).

## Acceptance Criteria

- **AC-1:** Given я открываю Настройки → Словарь, When страница загружена, Then я вижу таблицу замен: «От (Whisper пишет)» / «До (должно быть)» / «Действие» / «Область» / «Кнопки».

- **AC-2:** Given я хочу добавить замену, When я нажимаю «+ Добавить замену», Then открывается форма: поля «От» / «До» / «Область» (транскрипция / саммари / задачи / везде), «Регистр» (сохранять / игнорировать), кнопка «Сохранить».

- **AC-3:** Given я добавил замену «Postgre SQL → PostgreSQL», When идёт следующая транскрипция, Then все вхождения «Postgre SQL» в тексте автоматически заменяются на «PostgreSQL» (case-insensitive, сохраняя регистр surrounding).

- **AC-4:** Given у меня 30 замен в словаре, When я ищу «post», When отображается autocomplete с фильтрацией, я могу быстро найти и отредактировать нужную замену.

- **AC-5:** Given я хочу экспортировать словарь, When я нажимаю «Экспорт → JSON», Then скачивается файл для переноса на другой компьютер / шеринга с коллегами.

- **AC-6:** Given я хочу импортировать, When я выбираю JSON-файл и нажимаю «Импорт», Then замены добавляются (с дедупликацией).

- **AC-7:** Given я использую словарь в AI-корректировке (US-044), When идёт cleanup, Then LLM получает в промпте список замен как «обязательные исправления» (например, «Всегда используй PostgreSQL вместо Postgre SQL»).

- **AC-8:** Given словарь применяется, When я навожу на заменённое слово в транскрипции, Then вижу tooltip «Заменено по словарю: Postgre SQL → PostgreSQL».

## Технические заметки
- Хранение: `dictionary (id, user_id, from_text, to_text, scope, case_sensitive, is_regex, created_at)`.
- Применение:
  - Для транскрипции — сразу после Whisper (до/после пунктуации — настраивается).
  - Для AI — передача в system prompt для LLM.
  - Для DOCX — финальная замена перед экспортом.
- Case-insensitive по умолчанию; case-sensitive опционально.
- Поддержка regex: `is_regex=true` — для сложных замен.
- Whitelist для LLM: передавать только замены с `scope` включающим текущую операцию.
