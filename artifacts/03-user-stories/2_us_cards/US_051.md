# US-051: CPU режим — fallback при отсутствии GPU

| Поле | Значение |
|---|---|
| **ID** | US-051 |
| **Эпик** | EPIC-PERF |
| **Приоритет** | Must |
| **Story Points** | 3 |
| **Персона** | P-01 Алексей (Windows), P-02 Алексей (Astra, офлайн) |
| **Форма** | SettingsPage → TranscriptionTab |
| **API** | (внутренний конфиг) |

## User Story
**Как** Алексей (P-01) (P-02 в Astra Linux без дискретной видеокарты),
**я хочу** чтобы транскрипция работала на CPU, когда GPU недоступен или отключён,
**чтобы** приложение работало на любом оборудовании, не требуя обязательного GPU.

## Контекст
- **Процесс:** Транскрипция (фоновая операция).
- **Боль персоны:** «На рабочем ноутбуке (Astra Linux) нет NVIDIA — транскрипция должна работать на CPU, пусть медленнее».
- **Связь с Vision:** §7.1 — «CPU режим»; §9 Ресурсы; §5 Преимущество #9 «Кросс-платформенность».
- **KPI:** Latency CPU ≤2× realtime для модели medium (1 ч аудио = 2 ч обработки).

## Acceptance Criteria

- **AC-1:** Given GPU отсутствует или отключён, When я запускаю транскрипцию, Then используется CPU-режим автоматически (без ошибок).

- **AC-2:** Given CPU-режим активен, When идёт транскрипция, Then используется оптимизация:
  - Модель `medium` или `small` (large-v3 на CPU слишком медленная)
  - `compute_type="int8"` (quantization — экономит RAM, ускоряет на CPU)
  - `beam_size=1` (без beam search)
  - Многопоточность: все ядра CPU (`torch.set_num_threads(os.cpu_count())`)

- **AC-3:** Given CPU-режим, When я смотрю footer progress-bar (US-020), Then вижу «🖥 CPU (8 cores, int8)».

- **AC-4:** Given я на CPU, When я выбираю `large-v3`, Then появляется предупреждение «large-v3 на CPU будет в 10× медленнее. Рекомендуется medium. Продолжить?».

- **AC-5:** Given CPU-режим, When RSS приближается к 4 ГБ (US-032), Then автоматическое переключение на порционный режим (chunk=10 сек вместо 30 сек), скорость падает, но обработка продолжается.

- **AC-6:** Given я на CPU, When я могу включить GPU, я переключаюсь в настройках, и следующая транскрипция уже на GPU (без перезапуска backend).

- **AC-7:** Given Astra Linux (P-02) с 4 ГБ RAM и CPU, When я транскрибирую моделью `small` 1-часовую запись, Then обработка завершается за ~1 ч реального времени, RSS не превышает 3 ГБ.

- **AC-8:** Given CPU-режим активен, When я хочу ускорить, я могу подключить внешний USB-GPU (eGPU) с NVIDIA, и при следующем запуске приложение автоматически определяет GPU.

## Технические заметки
- Библиотека: `faster-whisper` (CTranslate2) — в 4× быстрее, чем openai-whisper на CPU.
- `compute_type="int8"` — quantization (минимальная потеря качества, ~30% ускорение).
- Многопоточность: `ctranslate2` использует все ядра по умолчанию.
- Vosk как ultra-lightweight альтернатива: ~50 МБ, работает на CPU в реальном времени, но WER хуже (~25%). Out of scope для этой US, упоминается в Vision.
- Мониторинг: `psutil` для RSS, `os.cpu_count()` для многопоточности.
