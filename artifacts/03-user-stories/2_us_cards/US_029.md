## User Story
**Как** Алексей (P-01),
**я хочу** после генерации саммари автоматически получить предложенные теги (LLM анализирует темы, участников, дату, контекст),
**чтобы** не придумывать теги вручную — достаточно подтвердить/отклонить предложенные.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — после саммари (US-022).
- **Боль персоны:** «Я ленюсь ставить теги вручную. Хочу, чтобы система предложила 3–5 релевантных тегов, я подтвержу».
- **Связь с Vision:** §7.1 — «Автотеги»; §6 Цель #6 «AI-фичи: тегирование».
- **Связь с US-028:** US-029 генерирует предложения, US-028 — ручное управление.

## Acceptance Criteria

- **AC-1:** Given саммари сгенерировано, When я открываю вкладку «Теги», Then я вижу секцию «🤖 Предложенные теги» (или «Авто-предложения») с 3–7 тегами от LLM (например, «postgresql», «миграция», «заказчик-X», «планёрка»).

- **AC-2:** Given я смотрю автотеги, When я нажимаю «✓ Подтвердить» рядом с тегом, Then он добавляется к протоколу и перемещается в секцию «Мои теги».

- **AC-3:** Given я нажимаю «✕ Отклонить», When отклоняю тег, Then он убирается из предложений, LLM больше НЕ предлагает его для этого протокола (запоминается в `rejected_tags`).

- **AC-4:** Given я нажимаю «✓✓ Подтвердить все», When все автотеги добавляются, Then они появляются в «Мои теги», счётчик уведомления уменьшается.

- **AC-5:** Given LLM-сервис недоступен, When я открываю теги, Then секция «Авто-предложения» пустая, появляется сообщение «Автотеги недоступны. Добавьте вручную».

- **AC-6:** Given LLM предлагает тег, который уже есть в «Мои теги», When отображается, Then он не дублируется, показывается как «✓ уже добавлен» (без возможности повторного добавления).

- **AC-7:** Given я отклонил все предложения, When я снова нажимаю «Сгенерировать автотеги», Then LLM предлагает новый набор (с учётом исключённых).

## Технические заметки
- Промпт для LLM: «Предложи 5–7 тегов для этого протокола. Теги должны быть: 1) краткие (1–3 слова), 2) информативные (тема/проект/участник/период), 3) в нижнем регистре, через дефис. Примеры хороших тегов: 'postgresql', 'миграция', 'заказчик-X', 'q4-2026'».
- Входные данные: саммари + список участников + название встречи + дата.
- Использует те же провайдеры, что US-022 (Hermes → GigaChat → Ollama).
- Хранение: `auto_tag_suggestions (id, protocol_id, tag_text, source, is_rejected, created_at)`.
