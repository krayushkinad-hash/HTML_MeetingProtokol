# US-011: Календарь прошлых встреч (месяц/неделя/день)

| Поле | Значение |
|---|---|
| **ID** | US-011 |
| **Эпик** | EPIC-HISTORY |
| **Приоритет** | Must |
| **Story Points** | 5 |
| **Персона** | P-01 Алексей (Windows), P-02 Алексей (Astra, офлайн) |
| **Форма** | CalendarView |
| **API** | GET /api/v1/calendar?year=&month= |

## User Story
**Как** Алексей (P-01, P-02),
**я хочу** видеть календарь прошлых встреч с переключением между месяцем/неделей/днём,
**чтобы** за 2 секунды найти «что было в прошлый вторник» или «все встречи октября».

## Контекст
- **Процесс:** Этап «Подготовка протокола» — шаг «Найти нужный протокол».
- **Боль персоны:** «Список из 50+ протоколов — листать неудобно, нужна визуальная карта по датам».
- **Боль P-02:** «В командировке без интернета — нужно быстро открыть календарь и найти протокол».
- **Связь с Vision:** §7.1 — «Календарь прошлых встреч»; §5 Ключевое преимущество #4 «Календарь».

## Acceptance Criteria

- **AC-1:** Given я на главной странице, When я переключаюсь на вид «Календарь», Then отображается календарь текущего месяца с цветными точками на датах, где есть протоколы.

- **AC-2:** Given я в виде «Месяц», When я нажимаю на дату с протоколами, Then ниже календаря появляется список всех встреч за этот день (с временем, названием, количеством участников).

- **AC-3:** Given я хочу другой вид, When я переключаю на «Неделя» или «День», Then календарь перерисовывается, точка/полоска становится больше.

- **AC-4:** Given у меня 200+ протоколов, When я открываю календарь, Then он загружается за ≤3 сек (KPI Vision: «Время старта в Astra Linux офлайн ≤3 сек»).

- **AC-5:** Given я нахожусь в Astra Linux без сети (P-02), When я открываю календарь, Then всё работает идентично Windows-версии — данные из локального IndexedDB.

- **AC-6:** Given я навожу мышь на дату, When ховер срабатывает, Then показывается tooltip «3 встречи: 14:00 Планёрка, 16:30 Заказчик Х, 17:30 Ретро».

## Технические заметки
- Данные из IndexedDB (для P-02 офлайн) + опционально API для синхронизации (для будущего).
- Библиотека календаря: FullCalendar (vanilla JS, без зависимостей от бэкенда).
- Цвет точки — по тегу/проекту (если есть автоматические теги — см. US-025).
