# US-044: Корректировка текста транскрипта через LLM (cleanup-text)

| Поле | Значение |
|---|---|
| **ID** | US-044 |
| **Эпик** | EPIC-AI |
| **Приоритет** | Should |
| **Story Points** | 5 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | ProtocolView → TranscriptTab → AI actions |
| **API** | POST /api/v1/llm/cleanup-text/{protocol_id} |

## User Story
**Как** Алексей (P-01),
**я хочу** после транскрипции запустить LLM-шаг «cleanup-text», который исправит типичные ошибки Whisper (повторы, слова-паразиты, неправильно распознанные термины),
**чтобы** получить более чистый текст без необходимости ручной правки.

## Контекст
- **Процесс:** Этап «Подготовка протокола» — после транскрипции (US-005) и пунктуации (US-006).
- **Боль персоны:** «Whisper выдаёт "это самое... ну типа... как бы" — хочу LLM-чистку от мусорных слов».
- **Связь с Vision:** §7.1 — «AI-корректировка текста»; §6 Цель #6 «AI-фичи».
- **Отличие от US-006:** US-006 — только пунктуация, US-044 — глубокая чистка (повторы, паразиты, термины).

## Acceptance Criteria

- **AC-1:** Given транскрипция и пунктуация готовы, When я нажимаю «AI-корректировка текста», Then LLM получает текст (чанками ≤3000 символов) и возвращает очищенную версию:
  - Удалены повторы («я я хочу», «это это»)
  - Удалены слова-паразиты («это самое», «ну типа», «как бы», «в общем-то» — где они не несут смысла)
  - Исправлены типичные ошибки Whisper по словарю (см. US-045)
  - Сохранены все содержательные слова

- **AC-2:** Given корректировка завершена, When я смотрю транскрипцию, Then я вижу «очищенный» текст, помеченный как «✨ AI-очищенный» (с возможностью сравнить с оригиналом через diff).

- **AC-3:** Given я хочу посмотреть diff, When я нажимаю «Показать изменения», Then я вижу side-by-side: оригинал | очищенный текст, изменения подсвечены (зелёный = добавлено, красный = удалено).

- **AC-4:** Given корректировка не понравилась, When я нажимаю «Откатить к Whisper-версии», Then текст возвращается к `text_raw` (после пунктуации, до AI-чистки).

- **AC-5:** Given LLM-сервис недоступен, When я пытаюсь корректировать, Then я вижу «AI-корректировка недоступна. Проверьте настройки AI-провайдера» (US-066), без падения pipeline.

- **AC-6:** Given я отключил AI-фичи в настройках (приватный режим), When идёт транскрипция, Then шаг cleanup-text пропускается.

- **AC-7:** Given я применяю словарь замен (US-045), When идёт корректировка, Then LLM учитывает пользовательские замены (например, «Postgre SQL» → «PostgreSQL»).

## Технические заметки
- Промпт: «Очисти следующий текст транскрипции совещания на русском языке. Удали повторы и слова-паразиты. Исправь типичные ошибки распознавания. Сохрани все содержательные слова. Верни только очищенный текст, без комментариев».
- Хранение версий: `transcript_versions (protocol_id, version_type, text, created_at)`:
  - `raw` — Whisper без пунктуации
  - `punctuated` — после US-006
  - `cleaned` — после US-044 (эта US)
- Diff: библиотека `diff-match-patch` или `python-Levenshtein`.
- Модели: Hermes Agent (US-039), fallback — GigaChat (US-038), Ollama (US-040).
