# US-054: Управление профилем пользователя

| Поле | Значение |
|---|---|
| **ID** | US-054 |
| **Эпик** | EPIC-SETTINGS |
| **Приоритет** | Should |
| **Story Points** | 2 |
| **Персона** | P-01 Алексей (Windows) |
| **Форма** | SettingsPage → ProfileTab |
| **API** | GET/PATCH /api/v1/hmp/user-setting |

## User Story
**Как** Алексей (P-01),
**я хочу** настроить свой профиль (имя, email, часовой пояс),
**чтобы** система корректно отображала мои данные и временные метки в протоколах.

## Контекст
- **Процесс:** Начальная настройка приложения, ежедневное использование.
- **Боль персоны:** «Дата в протоколе показывается не в моём часовом поясе».
- **Связь с Vision:** §7.1 Базовое ядро — «Single-user pattern».

## Acceptance Criteria

- **AC-1:** Given я открыл «Настройки → Профиль», When загружается страница, Then поля заполнены текущими значениями из БД.

- **AC-2:** Given я ввёл имя в поле «Имя», When я нажимаю «💾 Сохранить», Then запрос PATCH отправляется и Toast «Профиль сохранён» появляется.

- **AC-3:** Given я ввёл email в поле «Email», When я нажимаю «💾 Сохранить», Then email сохраняется (валидация формата).

- **AC-4:** Given я выбрал часовой пояс из списка, When я нажимаю «💾 Сохранить», Then новый timezone применяется ко всем датам в UI.

- **AC-5:** Given backend недоступен, When я пытаюсь сохранить, Then Toast «Ошибка: ...» с описанием.

- **AC-6:** Given поля не заполнены, When я нажимаю «💾 Сохранить», Then отправляется с пустыми значениями (или с дефолтами).

## Технические заметки
- Backend: PATCH /user-setting с partial update
- Frontend: использует `api.updateUserSetting({user_name, email, timezone})`
- Timezone: IANA формат (Europe/Moscow, America/New_York)
- Single-user: нет авторизации, все настройки глобальные
