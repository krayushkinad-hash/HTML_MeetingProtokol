# FORM_PROTOCOL_VIEW: Просмотр протокола с транскрипцией

## 1. Общие сведения

| Поле | Значение |
|---|---|
| **Идентификатор формы** | F-HMP-2 |
| **Название формы** | Просмотр протокола с транскрипцией и таймкодами |
| **Путь доступа** | `dist/protocol.html?id=<id>` или ссылка из списка протоколов / календаря |
| **Цель и назначение** | Просмотр готового протокола: реплики по ораторам, таймкоды, навигация по видео |
| **Этап бизнес-процесса** | P-01 «Подготовка протокола» — шаг «Просмотр результата» |
| **Входные данные** | protocol_id (UUID) |
| **Выходные данные** | Отображённый протокол с метаданными, репликами, плеером видео |

## 2. Структура и навигация

- **Шапка:** название протокола, дата, кнопки «Назад», «Экспорт», «Редактировать ораторов».
- **Левая колонка (30%):** видеоплеер с таймкодами; ниже — метаданные (участники, повестка, теги).
- **Правая колонка (70%):** транскрипция — список реплик с таймкодом, оратором, текстом. Каждая реплика кликабельна.
- **Подвал:** кнопки «К началу», «К концу», «Поиск по транскрипции».
- **Адаптивность:** на узких экранах (<800 px) колонки перестраиваются вертикально: видео сверху, транскрипция снизу.

## 3. Спецификация полей ввода

| № | Подпись | Тип | Обяз. | Default | Значения | Валидация |
|---|---|---|---|---|---|---|
| 3.1 | Поиск по транскрипции | text (search) | Нет | "" | — | Длина ≥2 символов для запуска поиска |
| 3.2 | Фильтр по оратору | select | Нет | "Все" | Список ораторов из протокола | — |
| 3.3 | Перемотка | slider (видео) | Нет | 0 | 0..длительность видео (сек) | Шаг = 1 сек |
| 3.4 | Скорость воспроизведения | select | Нет | "1.0x" | 0.5x, 0.75x, 1.0x, 1.25x, 1.5x, 2.0x | — |

### Отображаемые (не редактируемые) данные

| № | Поле | Тип | Источник |
|---|---|---|---|
| 3.10 | Название | text | `protocol.title` |
| 3.11 | Дата | date | `protocol.date` |
| 3.12 | Место | text | `protocol.location` |
| 3.13 | Председатель | text | `protocol.chair` |
| 3.14 | Участники | list | `protocol.attendees[]` |
| 3.15 | Повестка | text | `protocol.agenda` |
| 3.16 | Решения | text | `protocol.decisions` |

## 4. Поведение и события

| Событие | Реакция |
|---|---|
| Открытие страницы | Загрузка протокола по id; если нет в IndexedDB — запрос к backend `GET /api/v1/protocols/<id>`; отображение метаданных и реплик |
| Клик по реплике | Видеоплеер перематывается на таймкод реплики (`video.currentTime = utterance.start`) и начинает воспроизведение |
| Ввод в поле поиска | Через 300 мс фильтрация реплик: подсветка совпадений жёлтым, скрытие нерелевантных |
| Выбор оратора в фильтре | Показываются только реплики этого оратора; счётчик реплик обновляется |
| Кнопка «Экспорт» | Открывается FORM_EXPORT_DIALOG |
| Кнопка «Редактировать ораторов» | Открывается FORM_SPEAKER_EDITOR |
| Видео закончилось | Плеер ставится на паузу; активная реплика снимается; показывается тост «Воспроизведение завершено» |
| Протокол не найден | Красный баннер «Протокол не найден. Возможно, он удалён.» + кнопка «Назад» |
| Сеть недоступна (P-02) | Показ из IndexedDB; индикатор «Офлайн-режим» в шапке |
| Воспроизведение видео | Подсветка текущей реплики в правой колонке (синяя рамка) |

## 5. Ошибки и информационные сообщения

| Тип | Условие | Текст |
|---|---|---|
| Ошибка | protocol_id не передан | «Протокол не указан. Вернитесь на главную страницу.» |
| Ошибка | Протокол не найден | «Протокол не найден. Возможно, он удалён или повреждён.» |
| Ошибка | Видеофайл не найден | «Видеофайл не найден на диске. Проверьте, что файлы протокола целы.» |
| Предупреждение | Поиск без результатов | «Ничего не найдено по запросу «<текст>». Попробуйте другой запрос.» |
| Предупреждение | Видео большое (>500 МБ) | «Видео большое, загрузка может занять несколько секунд.» |
| Информация | | «Воспроизведение завершено» |
| Информация | Восстановление из IndexedDB | «Протокол загружен из локального хранилища (офлайн-режим)» |

## 6. Сценарии по умолчанию (Состояния)

- **Загрузка:** спиннер в центре страницы.
- **Готовый протокол:** реплики отображаются, плеер готов, видео не запущено.
- **Воспроизведение:** активная реплика подсвечена синей рамкой, плеер играет.
- **Поиск активен:** только релевантные реплики показаны, совпадения жёлтые.
- **Фильтр по оратору:** только реплики выбранного оратора.
- **Офлайн (P-02):** индикатор в шапке, метаданные и текст доступны, видео воспроизводится локально.
- **Только чтение:** все поля отображения только для чтения; редактирование — через FORM_SPEAKER_EDITOR и FORM_TRANSCRIPT_EDITOR.

## 7. Требования к данным (Маппинг)

- **Источник:** backend API или IndexedDB.
- **Пример JSON ответа:**

```json
{
  "id": "abc-123-def",
  "title": "Планёрка команды 14.09.2026",
  "date": "2026-09-14",
  "location": "Zoom",
  "chair": "Алексей К.",
  "attendees": ["Алексей К.", "Петров П.", "Сидорова А."],
  "agenda": "Статус задач, бюджет Q4, риски",
  "decisions": "1. До 15.09 отправить отчёт\n2. Увеличить ресурсы на backend",
  "speakers": {
    "SPEAKER_00": "Алексей К.",
    "SPEAKER_01": "Петров П.",
    "SPEAKER_02": "Сидорова А."
  },
  "utterances": [
    {
      "id": "utt-001",
      "start": 32.5,
      "end": 48.2,
      "speaker_id": "SPEAKER_00",
      "text": "По бюджету на четвёртый квартал — у нас осталось 1.2 миллиона."
    }
  ],
  "video_url": "/api/v1/media/abc-123-def/video",
  "duration_sec": 3600
}
```

- **Эндпоинт:** `GET /api/v1/protocols/<id>` — основной; `GET /api/v1/media/<id>/video?t=<sec>` — потоковое видео с таймкодом.
- **Локальное хранилище:** IndexedDB `protocols/<id>` (для офлайн).

## 8. Нефункциональные требования

- **Производительность:** отрисовка протокола с 1000 репликами за ≤500 мс; переход к видео по клику — мгновенный; поиск — ≤300 мс debounce.
- **Защита:** доступ только по локальному backend; никакой передачи данных наружу; HTTPS для удалённого доступа (если есть).
- **Горячие клавиши:** Space — play/pause; ←/→ — перемотка ±5 сек; Shift+←/→ — ±30 сек; Ctrl+F — фокус на поиск; Esc — закрыть редактор.
- **Кроссбраузерность:** Chromium 100+, Firefox 100+, Safari 14+; HTML5 `<video>` с поддержкой MP4/H.264 + AAC.
- **Масштабируемость:** виртуализация списка реплик (react-window-like) для протоколов >5000 реплик.
- **Доступность:** все реплики доступны с клавиатуры (Tab); активная реплика объявляется screen reader; видео имеет субтитры.

## 9. Технические требования

- **Frontend:** нативный `<video>` + кастомный плеер (без video.js для уменьшения зависимостей).
- **Backend:** FastAPI с эндпоинтом `GET /api/v1/media/<id>/video?t=<sec>` для потокового видео (HTTP Range поддержка).
- **Хранение:** видео в файловой системе (`~/.html_mp/protocols/<id>/video.mp4`); метаданные в IndexedDB.
- **Особые требования:** HTTP Range для докачки видео; ленивая загрузка транскрипции (по 100 реплик).

## 10. Примечания

- Форма не редактирует текст реплик — для этого отдельная FORM_TRANSCRIPT_EDITOR (US-009).
- Массовое выделение реплик (для тегирования) — расширение (не в MVP).
- Экспорт в формат Obsidian/Notion — расширение (v2).
- Цветовая маркировка ораторов — каждый оратор получает свой цвет (HSL с фиксированной насыщенностью и светлотой).
