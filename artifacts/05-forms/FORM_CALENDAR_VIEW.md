# FORM_CALENDAR_VIEW: Календарь прошлых встреч

## 1. Общие сведения

| Поле | Значение |
|---|---|
| **Идентификатор формы** | F-HMP-3 |
| **Название формы** | Календарь прошлых встреч |
| **Путь доступа** | Главная страница → переключатель «Календарь» в шапке |
| **Цель и назначение** | Визуальная навигация по истории протоколов (месяц/неделя/день), быстрый переход к нужному протоколу |
| **Этап бизнес-процесса** | P-01 «Подготовка протокола» — шаг «Найти нужный протокол»; P-03 «Подготовка в командировке» — поиск прошлых встреч |
| **Входные данные** | Список протоколов из IndexedDB (для офлайн) или с backend `GET /api/v1/calendar` |
| **Выходные данные** | Календарь с точками/полосами на датах с протоколами; список встреч выбранного дня |

## 2. Структура и навигация

- **Шапка:** переключатель видов (День/Неделя/Месяц), стрелки навигации (← сегодня →), кнопка «Сегодня».
- **Тело:** календарная сетка 7×6 (месяц) или 7×1 (неделя) или 24 часа (день).
- **Каждая ячейка дня:** число, цветные точки/полосы (по тегам/проектам), tooltip с краткой информацией.
- **Нижняя панель:** список встреч выбранной даты (время, название, число участников).
- **Адаптивность:** на узких экранах (<800 px) — компактный вид «День» по умолчанию; точки превращаются в числа.

## 3. Спецификация полей ввода

| № | Подпись | Тип | Обяз. | Default | Значения | Валидация |
|---|---|---|---|---|---|---|
| 3.1 | Вид календаря | radio | Да | "month" | "day", "week", "month" | — |
| 3.2 | Навигация | buttons (← / →) | Нет | текущая дата | — | Ограничение: ±5 лет от сегодня |
| 3.3 | Сегодня | button | Нет | — | — | Сбрасывает навигацию на текущую дату |
| 3.4 | Фильтр по тегу | select-multiselect | Нет | [] | Список тегов из протоколов | — |
| 3.5 | Фильтр по участнику | select | Нет | "Все" | Список участников | — |
| 3.6 | Поиск | text | Нет | "" | — | Поиск по названию протокола; debounce 300 мс |

### Отображаемые данные (только чтение)

| № | Поле | Тип | Источник |
|---|---|---|---|
| 3.10 | Дата с протоколами | cell | Все протоколы с полем `date` |
| 3.11 | Цвет точки | computed | Тег протокола (если есть) или хеш названия |
| 3.12 | Tooltip | text | Первые 3 встречи дня (время + название) |

## 4. Поведение и события

| Событие | Реакция |
|---|---|
| Открытие календаря | Загрузка всех протоколов из IndexedDB (≤100 мс для 200+ протоколов); вид «Месяц» по умолчанию |
| Клик по дате | Под календарём показывается список всех встреч за этот день; дата выделяется синим |
| Клик по встрече в нижней панели | Переход на FORM_PROTOCOL_VIEW с этим протоколом |
| Hover на дату | Tooltip «N встреч: 14:00 Планёрка, 16:30 Заказчик Х, 17:30 Ретро» |
| Переключение вида | Перерисовка сетки (месяц/неделя/день); дата выбора сохраняется |
| Переключение месяца | Анимация сдвига; данные загружаются лениво |
| Применить фильтр по тегу | Скрытие дней без протоколов с этим тегом |
| Применить фильтр по участнику | Скрытие дней без протоколов с этим участником |
| Поиск | Жёлтая подсветка дней с протоколами, в названии которых есть искомое слово |
| Сегодня | Клик кнопки перематывает на сегодняшнюю дату (текущий месяц/неделя/день) |
| Сеть недоступна (P-02) | Все данные из IndexedDB; индикатор «Офлайн-режим»; функционально идентично |

## 5. Ошибки и информационные сообщения

| Тип | Условие | Текст |
|---|---|---|
| Ошибка | IndexedDB недоступен | «Не удалось загрузить данные календаря. Проверьте, что браузер поддерживает IndexedDB.» |
| Предупреждение | Протоколов нет | «Пока нет ни одного протокола. Создайте первый через «Загрузить файл»» |
| Предупреждение | Много протоколов | «Загружено X протоколов. Фильтруйте по тегу или участнику для быстрого поиска.» |
| Предупреждение | Медленная загрузка | «Календарь загружается дольше обычного (>3 сек). Подождите…» |
| Информация | Клик по дате | Показ списка встреч дня |

## 6. Сценарии по умолчанию (Состояния)

- **Загрузка:** спиннер на месте календаря.
- **Пусто:** «Пока нет ни одного протокола» + кнопка «Загрузить первый».
- **Готов (месяц):** сетка с числами, точки на датах с протоколами, нижняя панель пуста до выбора даты.
- **Готов (неделя):** 7 столбцов, протоколы показаны полосами.
- **Готов (день):** временная шкала 24 часа, протоколы как блоки.
- **Дата выбрана:** дата подсвечена синим, в нижней панели — список встреч.
- **Фильтр активен:** часть дней скрыта, в заголовке «Фильтр: <тег>».
- **Офлайн (P-02):** всё то же, индикатор в шапке.

## 7. Требования к данным (Маппинг)

- **Источник:** IndexedDB (основной) + опционально `GET /api/v1/calendar?year=2026&month=9` для синхронизации.
- **Пример IndexedDB-объекта:**

```json
{
  "protocol_id": "abc-123-def",
  "title": "Планёрка команды",
  "date": "2026-09-14",
  "duration_sec": 3600,
  "tags": ["планёрка", "спринт-14"],
  "attendees": ["Алексей К.", "Петров П."]
}
```

- **Эндпоинт:** `GET /api/v1/calendar?year=<Y>&month=<M>` — список протоколов за период.
- **Локальное хранилище:** IndexedDB store `protocols`, индекс по `date`.

## 8. Нефункциональные требования

- **Производительность:** KPI ≤3 сек до первого отображения на Astra Linux офлайн с 200+ протоколами; перерисовка вида — мгновенная (<100 мс).
- **Защита:** все данные из локального IndexedDB; запрос к backend — только если есть синхронизация.
- **Горячие клавиши:** ←/→ — переключение месяца/недели; ↑/↓ — переключение недели (в виде «Месяц»); T — сегодня; 1/2/3 — переключение вида (День/Неделя/Месяц).
- **Кроссбраузерность:** Chromium 100+, Firefox 100+, Safari 14+; поддержка IndexedDB обязательна.
- **Масштабируемость:** поддержка до 10 000 протоколов с фасетным поиском и ленивой загрузкой.
- **Доступность:** календарь доступен с клавиатуры (Tab между датами); выбранная дата объявляется; ARIA role="grid".

## 9. Технические требования

- **Библиотеки:** FullCalendar (vanilla JS) или кастомная реализация на нативном JS.
- **Хранение:** IndexedDB `protocols` с индексом по `date`.
- **Backend:** FastAPI эндпоинт `GET /api/v1/calendar` (опционально).
- **Особые требования:** виртуализация списка встреч дня, если их >50; кэширование календаря на 5 минут для ускорения повторных открытий.

## 10. Примечания

- Цвет точки/полосы привязан к тегу (если есть) — одинаковые теги = одинаковый цвет.
- Если протоколов >500, по умолчанию показываются только встречи за последний год с кнопкой «Загрузить более ранние».
- Экспорт календаря в `.ics` (iCal) — расширение (v2).
- Печать календаря — поддерживается через CSS @media print.
