# FORM_EXPORT_DIALOG: Диалог экспорта в DOCX

## 1. Общие сведения

| Поле | Значение |
|---|---|
| **Идентификатор формы** | F-HMP-5 |
| **Название формы** | Диалог экспорта протокола в DOCX |
| **Путь доступа** | Из FORM_PROTOCOL_VIEW → кнопка «Экспорт» |
| **Цель и назначение** | Настройка параметров экспорта и формирование DOCX-файла |
| **Этап бизнес-процесса** | P-04 «Экспорт DOCX» |
| **Входные данные** | protocol_id, доступные скриншоты |
| **Выходные данные** | Сформированный DOCX-файл + ссылка для скачивания |

## 2. Структура и навигация

- **Модальное окно** (по центру экрана, с затемнением фона).
- **Шапка:** заголовок «Экспорт протокола в DOCX», кнопка «Закрыть» (×).
- **Тело:** секции настроек:
  - Секция 1: «Что включить» (чекбоксы: таймкоды, скриншоты, гиперссылки, группировка по ораторам)
  - Секция 2: «Группировка» (radio: по ораторам / сплошной список)
  - Секция 3: «Дополнительно» (чекбокс: водяной знак «Конфиденциально», текст заметки для участников)
- **Подвал:** кнопки «Отмена» и «Экспортировать».
- **Адаптивность:** на узких экранах модалка на весь экран.

## 3. Спецификация полей ввода

| № | Подпись | Тип | Обяз. | Default | Значения | Валидация |
|---|---|---|---|---|---|---|
| 3.1 | Включить таймкоды | checkbox | Нет | true | true/false | — |
| 3.2 | Включить скриншоты | checkbox | Нет | true | true/false | Доступно только если есть скриншоты |
| 3.3 | Включить гиперссылки на видео | checkbox | Нет | true | true/false | Доступно только если есть видеофайл |
| 3.4 | Группировать по ораторам | radio | Нет | "yes" | "yes" / "no" | — |
| 3.5 | Водяной знак «Конфиденциально» | checkbox | Нет | false | true/false | — |
| 3.6 | Заметка для участников | textarea | Нет | "" | — | Длина ≤500 символов |
| 3.7 | Имя файла | text | Да | auto | — | Без спецсимволов, ≤100 символов; auto = `protocol_YYYY-MM-DD.docx` |

### Отображаемые данные (только чтение)

| № | Поле | Тип |
|---|---|---|
| 3.10 | Название протокола | text |
| 3.11 | Дата | date |
| 3.12 | Оценка размера DOCX | text («~250 КБ без скриншотов, ~15 МБ со скриншотами») |
| 3.13 | Кол-во реплик | number |
| 3.14 | Кол-во скриншотов | number |

## 4. Поведение и события

| Событие | Реакция |
|---|---|
| Открытие диалога | Подгружаются метаданные протокола; автозаполнение имени файла; расчёт оценки размера |
| Изменение чекбокса «Скриншоты» | Пересчёт оценки размера; если скриншотов нет — чекбокс disabled |
| Изменение чекбокса «Гиперссылки» | Если видеофайл не найден — disabled с tooltipом |
| Нажата «Экспортировать» | Валидация имени файла; запрос к backend `POST /api/v1/export/docx`; показ прогресс-бара внутри модалки; после — ссылка на скачивание |
| Формирование завершено | Зелёный тост «DOCX готов», кнопка «Скачать», фокус на кнопке |
| Нажата «Отмена» | Закрытие диалога без сохранения настроек |
| Esc | Закрытие диалога (с подтверждением, если формирование идёт) |
| Ошибка формирования | Красный баннер внутри модалки; детали ошибки (расширенный режим) |

## 5. Ошибки и информационные сообщения

| Тип | Условие | Текст |
|---|---|---|
| Ошибка | Имя файла пустое | «Укажите имя файла» |
| Ошибка | Имя содержит спецсимволы | «Имя файла содержит недопустимые символы. Используйте только буквы, цифры, _ и -» |
| Ошибка | Нет реплик | «Невозможно экспортировать пустой протокол. Дождитесь завершения транскрипции.» |
| Ошибка | Скриншоты включены, но их нет | «Скриншоты недоступны для этого протокола. Опция отключена.» |
| Ошибка | Backend timeout (>30 сек) | «Формирование DOCX занимает больше времени, чем ожидалось. Подождите или попробуйте позже.» |
| Предупреждение | Размер >50 МБ | «Файл получится большим (>50 МБ). Рекомендуем отправить через облако, а не email.» |
| Информация | Формирование | «Формирование DOCX…» |
| Информация | Готов | «DOCX готов. Нажмите «Скачать» для сохранения.» |

## 6. Сценарии по умолчанию (Состояния)

- **Открытие:** все чекбоксы включены, имя файла заполнено автоматически.
- **Формирование:** модалка блокируется, прогресс-бар 0–100%, кнопки «Отмен» и/ и «Экспортировать» неактивны.
- **Успех:** зелёный тост, кнопка «Скачать», имя файла и ссылка скопированы в буфер.
- **Ошибка:** красный баннер, кнопки активны, можно повторить.
- **Скриншоты недоступны:** чекбокс «Скриншоты» disabled с tooltipом.
- **Видео отсутствует:** чекбокс «Гиперссылки» disabled.

## 7. Требования к данным (Маппинг)

- **Источник:** протокол из IndexedDB + параметры экспорта.
- **Пример JSON запроса:**

```json
{
  "protocol_id": "abc-123-def",
  "include_timestamps": true,
  "include_screenshots": true,
  "include_video_links": true,
  "group_by_speaker": true,
  "watermark": "Конфиденциально",
  "note": "Отправлено участникам встречи 14.09.2026",
  "filename": "protocol_2026-09-14.docx"
}
```

- **Пример JSON ответа:**

```json
{
  "task_id": "export-001",
  "status": "completed",
  "file_path": "/home/user/.html_mp/exports/protocol_2026-09-14.docx",
  "file_size": 254720,
  "duration_ms": 12500,
  "download_url": "/api/v1/exports/export-001/download"
}
```

- **Эндпоинты:** `POST /api/v1/export/docx` (запуск), `GET /api/v1/exports/<task_id>/download` (скачивание), `GET /api/v1/exports/<task_id>/status` (статус).
- **Локальное хранилище:** DOCX сохраняется в `~/.html_mp/exports/<task_id>/`.

## 8. Нефункциональные требования

- **Производительность:** формирование DOCX для 1-часовой встречи (без скриншотов) — ≤30 сек; со скриншотами (10–30 шт) — ≤60 сек.
- **Защита:** все данные локальны; backend формирует файл и отдаёт по локальному URL.
- **Горячие клавиши:** Esc — закрыть; Enter — экспортировать.
- **Кроссбраузерность:** Chromium 100+, Firefox 100+, Safari 14+.
- **Масштабируемость:** асинхронное формирование с прогрессом.
- **Доступность:** все чекбоксы связаны с `<label>`; модалка имеет `role="dialog"` и `aria-modal="true"`; фокус trapping.

## 10. Технические требования

- **Frontend:** нативная модалка (без библиотек) с focus trap.
- **Backend:** FastAPI с фоновой задачей (Celery / asyncio.Task) для формирования DOCX через python-docx по стандарту Краюшкина.
- **Формат файла:** DOCX с TNR 12, полями 20/10/10/10, заголовками 1/2/3, таблицами «Сетка таблицы».
- **Особые требования:** отслеживание прогресса через WebSocket или polling; возможность отмены формирования.

## 10. Примечания

- Шаблон DOCX — `scripts/render_vision_docx.py` (адаптирован для протокола).
- Гиперссылки на видео — относительный путь `file:./video.mp4#t=MM:SS` (см. US-017).
- Скриншоты подгоняются под ширину страницы (≤15 см).
- Если DOCX >50 МБ — предупреждение и предложение отправить через облако (Яндекс.Диск).
